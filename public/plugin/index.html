Eimu 插件包

把这个包交给你的 coding agent（Codex、Claude Code、Cursor、OpenClaw 或任何会说 MCP 的客户端），它就能直接用 Eimu 生成图片与视频。

包内文件

  • marketplace.json — 市集索引，只声明 eimu 这一个插件
  • eimu/.codex-plugin/plugin.json — 插件元数据
  • eimu/.mcp.json — MCP 端点，只有 URL，不含任何密钥
  • eimu/assets/eimu-icon.svg — 图标
  • eimu/README.md — 入口说明与装法
  • skills/film-production · character-consistency · camera-motion

现在怎么用

  • MCP 端点：POST https://eimu.dev/api/mcp（JSON-RPC 2.0 / Streamable HTTP），认证 Authorization: Bearer sk-biz-…
  • 逐客户端可复制配置：https://eimu.dev/mcp
  • 密钥自助签发：https://eimu.dev/settings/api-keys（只显示一次）

市集一键安装（codex plugin marketplace add → codex plugin add eimu@eimu）需要公开市集仓库托管本目录，尚未发布；发布前请走上面的 MCP 手动配置。

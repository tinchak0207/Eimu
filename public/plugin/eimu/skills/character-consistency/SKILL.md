# 角色一致性

## 原则

- 一致性只靠两件东西：**文字外形锚**（每次原样带上）与**参考图链**（每次都放进 `reference_images`）。不要指望模型运气。
- `generate_image` 的 `reference_images` 一次最多 5 张：角色定妆永远占第一张，场景与道具不要挤掉它的名额。
- Eimu 的 MCP 没有角色库、没有跨工程引用、没有画布分组。锚点由你在对话与文件里自己维护，图片一律用 URL 传递。
- 改锚是重大动作：改了就要重新出定妆图并把它升级为新锚，旧锚留档。

## 步骤

1. 写外形锚（十行以内，每条都要能画）：年龄段 / 脸型 / 五官 / 发型与发色 / 身形比例 / 服装（面料与配色）/ 配饰 / 惯用表情 / 一到两个标志性细节。之后每次调用原样粘贴，不改措辞、不换同义词。
2. `list_models` 挑一个支持参考图输入的图像模型；`get_quota` 确认余额。
3. `generate_image` 生成定妆参考图：水平白底三视图，左正面近景、中正面全身、右背面全身。prompt = 外形锚 + 视图与构图要求 + 「三格的身份、发型、服装、年龄、体型比例与配色必须完全一致」。
4. 把定妆图 URL 记为 `ref_hero`，后续所有出图都放进 `reference_images` 的第一位。
5. 逐镜生成：`generate_image`，prompt = 外形锚 + 该镜动作与环境，`reference_images = [ref_hero, 该场景图]`，`model` 与上一步保持同一个，`size` 跟随项目画幅。
6. 漂移检查（由用户或你逐镜比对）：换脸、改变发色、服装细节丢失、体型比例变化、配饰消失。命中任意一条就处理，不要继续往下画。
7. 修漂移用 `edit_image`（`image` 取漂移的那张或定妆图，`prompt` 写明把哪一处改回原样），不要重出一张新的——重出会引入第二套长相。
8. 做回锚：每 3-4 镜用**最初的定妆图**当参考，而不是上一镜的产物，避免误差逐镜累积。
9. 需要换装、换年龄或换季节时，先 `edit_image` 得到变体，把它注册为新锚并说明从哪一镜开始生效；同一段戏里不要混用两个锚。
10. 关键帧或定妆要入链前先用 `upscale`（`factor` 2 起，`size` 取 `2k`）提升细节，模糊的参考会把模糊传给后面每一镜。
11. 角色要动起来时用 `generate_video`，prompt 里继续带外形锚与服装描述；异步结果用 `get_result`（`kind: "video"`, `id` 为返回 id）轮询。
12. 交付时报告：外形锚原文、定妆图链接、逐镜链接、做过回修的镜号与原因、以及仍然存在的不一致（诚实列出，不要美化）。

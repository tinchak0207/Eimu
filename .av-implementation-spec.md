- trace：getOrCreateTraceId/withTraceId（src/lib/request-trace）；冪等：Idempotency-Key header（submitGenerationCommand 已處理，IdempotencyConflictError → 409 idempotency_key_reused）。

## 12. src/lib/biz-av-pipeline.ts（新）+ biz-av-pipeline.test.ts
```ts
export type AvSubmissionKind = "tts" | "avatar" | "lipsync";
export interface TtsSubmission { modelId: string; text: string; voice: string | null; speed: number | null; format: string | null; callbackUrl: string | null; }
export interface AvatarSubmission { modelId: string; presenterId: string | null; imageUrl: string | null; audioUrl: string | null; text: string | null; voice: string | null; resolution: string | null; callbackUrl: string | null; }
export interface LipsyncSubmission { modelId: string; imageUrl: string; audioUrl: string; resolution: string | null; callbackUrl: string | null; }
export type AvParseResult<T> = { ok: true; value: T } | { ok: false; message: string; code: string };
export function parseTtsBody(body: unknown): AvParseResult<TtsSubmission>
export function parseAvatarBody(body: unknown): AvParseResult<AvatarSubmission>
export function parseLipsyncBody(body: unknown): AvParseResult<LipsyncSubmission>
export function avPromptFor(kind: AvSubmissionKind, submission: TtsSubmission | AvatarSubmission | LipsyncSubmission): string
export function avWorkflowFor(kind: AvSubmissionKind, submission: TtsSubmission | AvatarSubmission | LipsyncSubmission): Record<string, unknown>
export const AV_DEADLINE_MS: { tts: number; avatar: number; lipsync: number } // 300_000 / 720_000 / 720_000
```
校驗規則：
- 共通：model 必須非空 string；callback_url 可選 http(s) ≤2048；voice/presenter_id 模式 /^[A-Za-z0-9_.\-]{1,128}$/（非法 400 invalid_voice/invalid_presenter_id）；url 欄位必須 http(s) 且 ≤2048（invalid_url）。
- tts：input 或 text 擇一（優先 input）非空 ≤10_000 字元（missing_input/prompt_too_long）；speed 數字 0.5–2（越界 clamp 到區間，非有限數字 400 invalid_speed）；response_format 或 audio_format ∈ mp3|wav|flac|pcm（其他 400 invalid_format）。
- avatar：presenter_id 與 image_url 至少一個（missing_source）；input/text 與 audio_url 至少一個（missing_script）。
- lipsync：image_url 與 audio_url 都必填（missing_image_url / missing_audio_url）。
- n 欄位若存在且 Number(n) !== 1 → 400 invalid_n（"n must be 1 for AV pipelines."）。
avPromptFor：tts→text；avatar→text ?? `[audio] ${audioUrl}`；lipsync→`[lipsync] ${imageUrl} ${audioUrl}`。
avWorkflowFor：tts → {voice, speed, format}（null 略）；avatar → {presenterId, imageUrl, audioUrl, voice, resolution}（null 略）；lipsync → {imageUrl, audioUrl, resolution}。
測試（純函數）：缺欄位各 400、speed clamp、url 校驗、lipsync 雙必填、n≠1 拒絕、prompt/workflow 生成斷言。

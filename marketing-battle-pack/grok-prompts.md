# Grok 搜索提示词（每天早晚各跑一次）

## Prompt ① 找落点

```
搜索X，范围严格限定：只看中文帖（简体+繁体），排除任何英文帖。
第一步：列出华语AI创作圈最活跃的20个KOL（粉丝≥1万，方向覆盖AI生图/AI视频/提示词/独立开发，类似宝玉@dotey、歸藏@op7418这种量级）。
第二步：从他们【过去24小时】的帖子中，按赞+转+评排序，取前10条。
输出表格，每行包含：
①帖子完整链接 ②作者handle ③发布时间 ④赞/转/评数
⑤主题一句话 ⑥评论区主流情绪（夸/骂/求教程/在吐槽什么）
⑦与「AI视频生成、分镜、角色一致性、一句话出片」的相关度0-10分。
只要≥6分的。不要英文结果，不要总结，直接上表。
```

## Prompt ② 找伤口（每周两次）

```
在X搜中文帖（简体+繁体，排除英文），最近7天，找正在抱怨以下痛点的高互动帖（≥50赞 或 评论≥20）：
①AI视频角色/画面不一致——换脸、服装漂移、第N镜崩
②分镜/故事板贵、慢、找不到人画
③提示词不会写、调不出想要的效果
④视频生成排队久、太贵
⑤短剧/电商内容产能跟不上
每条输出：链接｜作者｜原帖全文｜赞评数｜他具体卡在哪一步。
最多15条，按互动数降序。只要中文圈。
```

## Prompt ③ 回填取证（选中帖子后用）

```
对下面这几条帖子，逐条提取并原样输出：
①原帖全文（一字不改）
②点赞最高的前5条评论原文
③作者发这条的真实意图（炫技/求助/带货/吐槽）
④评论区此刻最想听到的一句话是什么
[在这里贴上你选中的帖子链接]
不要美化，不要概括，我要原文。
```

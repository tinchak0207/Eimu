# 歌词与作曲分工全文

## 歌词与作曲分工
【歌词创作路由】用户只要歌词/作词/填词/歌词精修，必须用 subagent_dispatch(expert:"lyricist")，单步任务也一样；不调用 music_gen。完整歌曲需要原创歌词时先派 lyricist，收到完成后 read 完整落盘文件并按歌词 skill 验收，再把全文和来源路径交给 music 作曲编曲；二者不可并发，不能先生成音频后补词。用户已提供完整原词且未要求精修时直接交给 music 原样谱曲；纯器乐/BGM不派歌词专家。这条规则在野兽模式开启或关闭时均生效。
- **纯歌词独立文字合同**：only-text 歌词只用 lyricist 的文字交付合同，交完整歌词与文件，不要求 `audio_url`／`duration_source`，不以 `FAILED` 占音频字段。先核对实际注册，尚未接入时如实说明当前歌词写作能力未接入，不以 music 工种冒充；对用户仍只说产品结果，不播报内部合同或路由。
- **歌词验收判准**：验收歌词须报「演唱字数 ÷ 预算 = Z%」（预算＝目标秒数×BPM÷60×每拍音节数；目标秒数 = min(用户明确要求, FlowMusic2API 成品实测区间小值 165s)，用户未给时长用 165s、BPM 未定先定一个（缺省 88）；单曲演唱字数硬上限 ≤400 字；自撰稿 Z >100% 不得直接生成、先删到 ≤100%；用户锁定原词走披露制＋三条出路）；演唱正文（`lyrics`）不得含装饰性空格断句，一处一句、必要处用标点。

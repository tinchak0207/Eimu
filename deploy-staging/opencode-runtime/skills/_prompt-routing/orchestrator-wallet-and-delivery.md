# 开局钱包／交付诚实细则（按需；主会话 AGENTS §4.4 指针）

> 从 AGENTS.md §4.4 外移的事故反例与细则。主会话只留短规；需要处理争议口径时再读本档。

## 4.4 开局钱包预检与选档纪律（硬规则，2026-09-30 R9）

- **第一轮回复前先查余额（含禁生成／纯规划）**：用户每一轮任务——**含明确「不生成／只要方案／只研究／只铺文本节点」**——在第一轮可见回复前必须先调 `quote_bundle`（免费；只查余额必须显式传 `balance_only:true`，空参数会被拒；要报价必须带 `items`，禁止把余额查询的结果说成「合计 0 币」）。开场可见正文须同时出现：**当前余额 X 币**（数字来自回执）＋本轮承诺（禁生成／不做付费生成 → **本轮零生成、零扣费**；若本轮要付费生成 → 按下方报方案币数）。禁止只写「零扣费／不产生费用」却不报余额数字（R2-G2：规划任务相对 R1 退步＝缺 `balance_only`）。返回 `spendable:false`（余额 ≤0）或 `affordable:false` 时，**回复第一句就讲「当前余额 X 币，本方案需 Y 币，差额 Z 币」**，再给最便宜可行方案——禁止先写十分钟企划/剧本/分镜才发现没钱。
- **规划／禁生成不要灌成片生成位（R2-G1）**：用户明确「禁生成／只要方案／纯策划／不要成片」时，网关开场骨架会自动瘦身（只留 text／结构，无 image／video／audio／film／config 空壳与 image_generate 工具卡）。助手不得再呼叫生成类工具，也不得用 `workflow_write` 主动补回生成位空壳；用文本节点／`document_upload` 交付策划。成片生成需用户另开明确生成回合。
- **计划骨架要如实说（2026-10-10 R5）**：本轮若画布被铺了计划骨架（出现新节点），必须在首条可见正文里用一句说明白（如「已按模板在画布铺好文字骨架，本轮不生成、不计费」）。实测反例：用户明说「先不要生成」，画布出现 20 个节点，而正文写「你说了先不生成，本轮就停在这里」——用户看画布会以为凭空多了东西。骨架是产品行为、不是你亲手生成，但**不说明就是让用户误判**。
- **落选 take 不得承诺删除（2026-10-10 R5）**：多版本生成后，落选版本的音频仍在平台存储、**没有删除端点**；不得承诺「帮你删掉其余几个版本」。正确说法＝「那一版不采用、不作为交付」；若用户指的其实是画布节点，先确认真实对象再动手删节点。实测反例：同一会话里一边承认「落选版都还在、不删」，一边承诺「核到之后立刻只留你选中的那一版、删掉其余两个」。
- **交付文本不得用代码栅栏裹（2026-10-10 R6）**：用户可见的歌词／歌词卡／交付文本一律用正文纯文本、表格或引用块交付；**禁止用代码栅栏（三反引号）包裹**——出站繁→简收口对栅栏内内容按设计放行（那是为保护代码），栅栏里的歌词会连实时正文一起原样外发。实测反例一：用户说「用代码块包起来方便我复制」，四行繁体歌词在实时 SSE 正文里一字未转；反例二：用户说「逐字原样、保持繁体」，交付的 .md 正文整篇繁体（交付文件不经过出站收口）。用户要「方便复制」就给纯文本行，并说明平台规范统一简体。
- **「一字不改」不是话术（2026-10-10 R6）**：不得口头保证「用词一字未改／机制保证」，除非①把「禁止改写、照录原词」明确写进派给 lyricist／子代理的 spec，②交付时给出可核验的核验方式（如逐行字数复算）。实测反例：用户明说「一个字都不要动」，子代理仍默认删词出精修版，靠复核才回退；同一段里既有「用词一字未改」又有「14 个字换了写法（31%）」＝自相矛盾。
- **表外字形不得归因平台规范（2026-10-10 R6）**：平台的繁→简是逐字表，表外字形（如「妳」）不会被转换；这类替换只能说是你自己做的并说明理由，不得写成「平台规范要求」。
- **用户引用的前提不存在要点破（2026-10-10 R6）**：用户提到你从没说过的事（实测反例：「不要之前说的曲风」，而上一轮从头到尾没提过任何曲风）时，必须先点破「此前没有说过这个」，不得顺着不存在的前提往下推进。
- **节点已落盘禁用「打开画布即可」族（R2-G2）**：本轮 `workflow_write`／`canvas_apply_ops` 已成功写入节点（含 `queued:true` 写穿快照）后，助手正文**禁止**出现「请打开画布」「打开画布即可看到」「打开画布即可查看」「打开即可看到／查看」等把打开画布当作业的话术。改为：列**节点标题清单**（来自回执 `summary`／steps／created 标题），和／或本轮 `document_upload` 得到的公网链接。可说「画布已铺好 N 颗节点」陈述事实；不可再扔「打开即可看到」。
- **报价只认 quote_bundle**：视频单价＝目录秒价×时长（`price_source:"catalog_per_second"`），禁止自己按 5 币/秒 心算；`estimate_unverified`/`unknown` 项对用户标「待确认」。`over_cap_items` 非空＝超出用户给的单价上限，必须点名。
- **未知价不作预算保证**：单价或计费单位未知，订单总额及余额能否覆盖均不可判定；已知项目单列，未知项不计为 0，不得先付费生成核价。站内金币、上游成本与上游额度分别说明，不混算。
- **让用户选档（A/B/C）后，未回复前只做免费步骤**（文案、分镜草稿、查价、查模型状态），禁止自行开始任何付费生成；想不停工就直接替用户选最便宜的可行档并明说「已按最便宜档 X 执行」，二者择一，不许问了又不等。

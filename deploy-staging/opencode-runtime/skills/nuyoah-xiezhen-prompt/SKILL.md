# nuyoah-xiezhen-prompt

## 目标

把用户的写真意图变成可直接提交生图的中文提示词，或把图片拆成可复用的视觉关键词。只关注画面逻辑、完成度和图像质量，不添加额外说教或无关解释。

## 入口判断

先选择一种输出模式：

- 用户说“系列母版、一整套系列、系列规划、固定格式”时，输出系列母版。
- 用户说“变体、同系列、创作变体、仿拍扩展”时，输出同系列变体关键词链。
- 用户说“完整、详细、精准控制、复刻、直接生图”时，输出详细提示词。
- 用户说“抽卡、网页端、大量生成、短关键词、开盲盒”时，输出 6–8 行抽卡关键词。
- 用户给图片并要求拆解时，输出图片关键词；组图先提取共同视觉 DNA，再列单张差异。
- 用户给出 `主题：`、`成年韩系混血甜酷辣妹，`、`关键词：` 三段骨架时，优先使用项目中的“网页端三段式风格探索 Prompt”。
- 用户说“文化视觉溯源、文化元素、往外扩展灵感”时，优先使用项目中的“图片文化视觉溯源与灵感扩展法”，区分事实、强关联和灵感联想。

需要生成、扩写、诊断、拆图或套用输出格式时，读取 [提示词逻辑与模板](references/prompt-logic.md)。
维护或回归验收本 Skill 时，读取 `evals/skin_reflection_cases.json`，至少覆盖直闪近景、直闪全身与有事件依据的真实汗光，防止把“去油腻”误修成所有场景统一哑光。

## 执行原则

1. 先判断画面为什么成立，再写细节。默认顺序为：妆容母体 → 同系妆容变体 → 发型与服饰 → 道具 → 构图 → 镜头 → 动作表情 → 光线 → 场景。
2. 用户提供人物参考图和目标系列时，参考图只保留五官辨识度；目标系列接管妆容、发型、服装、场景、道具、光线和情绪。
3. 用户明确棚拍时，使用低变量棚拍背景，不扩展成生活地点。
4. 默认人物为成年年轻女性，强调成年后的青春、灵动和生命力；不写未成年或儿童化表达。
5. 同系列变体只固定“整体风格词链”和“成像机制词链”，每张重新设计构图、动作、妆造、场景和现场光线；成像机制可以固定媒介、镜头响应和整体反差，但不能把同一方向、强度、落点和皮肤高光宽度的闪光复制到所有景别。最终输出连续关键词链，不显示内部分析模块。
6. 图片拆解只写可见事实；不确定内容标为“疑似”，不编造品牌、摄影师、器材或历史来源。
7. 用户没给足主题且无法合理推断时，只问一个简短问题。
8. 皮肤质感必须区分“纹理”和“反射”：`真实皮肤微纹理`不能替代底妆干湿、T 区油光、脸颊漫反射和局部高光范围。直闪、轻微过曝、水润唇或近景同时出现时，必须按景别控制皮肤反射，避免把唇部水润扩散成全脸油膜。

## 输出

- 直接交付用户触发的提示词或拆解结果，不输出分析过程。
- 详细提示词和系列母版按参考文件中的固定模块填满；抽卡版保持短促；变体版保持紧凑连续。
- 穿搭只写服装，饰品放入道具；场景与道具分开。
- 光线写清来源、方向、在人身上的落点和成像结果。
- 近景、直闪或高光妆面要同时写清皮肤底妆质地、反光区域和高光范围；没有水光肌或出汗证据时，默认自然半哑光或克制缎光，不默认全脸湿亮。
- 不用“高级、氛围感、电影感”替代可观察的成像描述。
- 默认中文，仅保留模型更易理解的摄影英文词。

## 更新本 Skill

只有用户明确要求检查或更新“南鸢写真提示词 Skill”本身时才进入本流程；普通写真提示词请求不得检查网络版本。

1. 先解析当前 Skill 的真实路径。若它位于维护者私有真源 `nuyoah-skills/skills/nuyoah-xiezhen-prompt/`，不得用公开发行版覆盖；说明这是维护真源，并改走维护者发布流程。
2. 对普通安装，先执行 `npx skills list -g` 确认全局安装存在，再执行 `npx skills update nuyoah-xiezhen-prompt -g -y`。
3. 若当前安装没有可更新的 lock 记录，使用官方公开源重新安装：`npx skills add nuyoah-ai-works/nuyoah-xiezhen-prompt -g -y`。不得改用不透明的一键脚本或 `curl | shell`。
4. 更新后读取实际安装目录中的 `SKILL.md`，回报安装位置以及 `metadata.version`。再读取 `https://knowledge.nuyoahonline.com/api/skills/nuyoah-xiezhen-prompt/manifest`；可访问时核对版本与发行哈希，暂时不可访问时如实说明没有完成网站镜像回读。
5. 明确提醒：当前任务已加载的旧 Skill 不会热更新；新建任务或重新加载 Agent 后，新版本才会进入上下文。

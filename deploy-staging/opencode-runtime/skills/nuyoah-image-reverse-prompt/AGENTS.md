# 南鸢图片反推 Skill 约定

## 真源

- `nuyoah-skills/skills/nuyoah-image-reverse-prompt/` 是本 Skill 的唯一可编辑真源。
- 生图工作知识库中的原路径只保留软链接；用户级安装也只允许指向本目录，不在入口位置维护副本。
- 公开仓库和知识站 ZIP 都是由本目录生成的只读发行物，不得反向覆盖真源。

## 范围

- 普通调用只输出图片类型、按类型逐项展开的字段级拆解、参考色卡、适用时的“成像签名”和可直接复制的中文生图提示词。
- 所有面向用户展示的区块标题和字段名必须使用中文，不得出现英文、拼音、下划线字段或中英并列标题；英文内部键只允许存在于用户明确要求的机器记录中。
- 每个有证据的字段必须独立成节；不得再压缩为笼统的“画面结构拆解”列表。
- 完整 prompt 必须覆盖所有会改变生成结果的已展示字段，并按生成优先级排列。
- 当前图片能读取真实像素尺寸时，画幅比例必须由宽高计算；只有没有尺寸信息时才允许视觉估算。
- 反推不能停在底层现象描述；当多项证据共同构成稳定成像签名时，必须先按“固有属性、光线、曝光、后期/渲染”分层，再归纳成受控复合术语。
- 复合术语必须带必要证据、排除条件和清晰度边界；证据不足时退回窄描述，不猜术语。
- 真人摄影时尚海报使用自己的公开控制字段，不把摄影人像字段和海报字段全部叠加；默认描述文字的层级、位置、字重和遮挡功能，不复刻具体文案，除非用户明确要求保留文字。
- 不接入外部反推服务，不保留第三方复刻模式，不输出额外的姿态分析附件。
- 生图与返图对比只用于用户明确要求的 Skill 校准，不是普通调用步骤。
- 自更新只在用户明确点名更新“南鸢图片反推 Skill”时触发；维护者私有真源不得被公开发行版覆盖。

## 维护

- 只把跨图片可复用的类型路由、观察字段、提示词顺序和失败防线写入参考文件。
- 单张图片的服装、人物、姿势、道具、颜色和场景不得沉淀为默认值。
- 修改后检查正例、反例、近邻触发，并至少回归真人摄影、动漫插画、海报设计三个类型。
- 每次公开发布必须更新 `SKILL.md` 的 `metadata.version`，先验证公开仓库和知识站不可变发行包，再推进最新版本清单。
- 结构调整或重要更新同步项目根目录 `工作记录.md`。

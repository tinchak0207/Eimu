# 冻结历史工具

这里保留原始文件字节，不再作为当前操作手册。

- `incidents/`：特定日期/事故的复测和一次性回填。
- `experiments/`：旧模型校准、A/B 实验、浏览器 relay 探索。
- `windows/`：旧 PowerShell/Vercel 探针，不适用于当前 Arch Linux 维护入口。

迁移前均位于 `tools/<文件名>`。这些文件中的旧命令、相对 import、样本路径、生产地址和运行假设是历史内容，**并未被适配为在本目录直接运行**。不要把复制回根目录当恢复步骤；需要复用时，从当前 `qa/`、`codegen/`、`ops/` 的真实入口提取所需行为，再核对当下契约和授权。历史文件不参与当前 TypeScript 编译与发布。

保留原文用于追溯，不把历史事故脚本当现役检查或功能证明。

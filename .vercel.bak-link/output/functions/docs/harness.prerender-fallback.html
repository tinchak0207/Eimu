DeepSeek Harness

DeepSeek Harness 零基础入门教程

DeepSeek Harness（简称 dsh）是 DeepSeek 开源的 AI 智能体框架：装上它之后， 你可以用自然语言让 AI 帮你读代码、写代码、跑命令。本教程面向完全没接触过的用户，照着做就能跑起来。 全程大约 15 分钟。

已经跑通了？去读深度指南
01

安装 Node.js 和 pnpm（5 分钟）

打开官方下载页 nodejs.org，点页面中间绿色的 LTS 版本下载，双击安装包，一路点「下一步」直到完成。

装好后打开终端（Windows：按 Win + R，输入 cmd 回车；Mac： 打开「终端」App），粘贴下面这行并回车，看到版本号就说明装好了：

node -v

需要 v22.19 或更高的版本号。如果版本较旧，去 nodejs.org 重新下载最新的 LTS 覆盖安装即可。

再从源码运行还需要 pnpm。在终端粘贴并回车，看到版本号即成功：

npm install -g pnpm
pnpm -v
02

从源码包启动（拿到 zip 用这个方式）

把你拿到的 deepseek-harness-master.zip 解压到一个好找的文件夹 （路径不要有中文和空格，例如 C:\dsh）。然后在终端里依次执行：

cd C:dshdeepseek-harness-master
pnpm install
pnpm run build
pnpm dsh web

第一次安装会下载依赖，耐心等它跑完。pnpm run build 会构建全部包和前端 （需要几分钟）。看到类似这样的输出，就成功了：

Local: http://127.0.0.1:3080
03

不想碰源码？一行命令安装

如果你其实不需要源码、只想快速体验，就不用解压 zip——在终端粘贴下面这行并回车，它会自动下载 并启动 Web 界面：

npx @deepseek-ai/dsh web

第一次运行会问你是否安装 @deepseek-ai/dsh，输入 y 回车即可。看到 Local: http://127.0.0.1:3080 就算成功。

04

打开界面，填入 DeepSeek API 密钥

浏览器访问 http://127.0.0.1:3080（启动命令的终端窗口不要关闭，关闭它等于 关掉服务）。

打开 platform.deepseek.com 注册并登录，在「API Keys」页面点「创建 API Key」，复制生成的密钥（形如 sk-xxxxxxxx）。

回到 Harness 界面，点 设置 → 模型，在 DeepSeek 卡片里粘贴密钥并保存。密钥是 只写的：保存后网页不会再次显示它，这是正常的安全设计。到这里模型就配好了，不需要重启。

05

选择工作区

工作区就是你想让 AI 帮你干活的文件夹（比如你的项目目录）。点界面的 选择工作区，找到并选中你的项目文件夹。选中之前，输入框是灰的不能打字，这是 正常的。

之后 AI 就能读取、修改这个文件夹里的文件，并在这个目录里运行命令。

06

发出你的第一个任务

在输入框里输入下面这句话，回车：

帮我总结这个项目的结构，并说明它有哪些主要模块。

AI 会开始思考、读文件、运行命令。当它想做需要你批准的操作（例如修改文件、执行命令）时，界面会 先询问你，点确认就继续。右侧会逐条展示它的思考过程和结果。

以后你可以让它写代码、修 bug、整理文档、批量处理文件，只要把需求说清楚就行。

常见问题

提示 node 版本太低 / 命令不认识？

重新去 nodejs.org 下载最新的 LTS 版覆盖安装，然后关掉终端重新打开，再执行 node -v 确认版本高于 v22.19。

pnpm install 卡住 / 下载很慢？

国内网络访问 npm 可能较慢。可以换成国内镜像源再试：npm config set registry https://registry.npmmirror.com，然后重新执行 pnpm install。

pnpm run build 报错？

最常见原因是 Node.js 版本太旧或安装不完整。先确认 node -v ≥ v22.19，再删除 node_modules 和 pnpm-lock.yaml 重新 pnpm install && pnpm run build。

提示 MISSING_CREDENTIAL？

说明模型页里没有保存密钥。回到「设置 → 模型」，给 DeepSeek 填入 API Key 并保存。

提示 UNKNOWN_MODEL？

说明选中的模型还没配置。在「设置 → 模型」里选一个已配置的模型，再回来发任务。

输入框一直不能打字？

还没有选择工作区。点「选择工作区」选中你的项目文件夹后再试。

关了终端再打开，网址打不开了？

正常——服务随着终端关闭而停止。重新执行启动命令（源码方式 pnpm dsh web / 一行命令方式 npx @deepseek-ai/dsh web）即可再次启动。

TIP：想了解每个文件夹是干什么的、怎么改配置、怎么装插件、怎么用代码调用——见 深度指南。本教程介绍的 Harness 是 DeepSeek 官方的开源本地工具，与本站的 API / MCP 服务相互独立。

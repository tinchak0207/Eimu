Agent 集成

把Eimu接入你的 AI Agent

通过 MCP（Model Context Protocol），Claude、Codex、Cursor 等 agent 可以调用我们的生成能力——你说一句话， agent 帮你出图、出视频，并拿到成品 URL。

一、原理

MCP server 跑在你的电脑上（stdio 模式），用你的 B 端密钥sk-biz-…调我们的 OpenAI 兼容 API。agent 看到的是 4 个工具，背后走的是同一套计费与队列。

二、准备密钥

密钥走 充值页 或联系站方签发。签发后只显示一次，请妥善保存。

# 用密钥验证连通性（也适用于直接 REST 调用）
curl https://image.tinchak0207.xyz/v1/models \
  -H "Authorization: Bearer sk-biz-你的密钥"

三、安装 MCP server

克隆仓库后构建：

git clone <仓库地址> github-image-json-new-api-https
cd github-image-json-new-api-https/mcp-server
npm install
npm run build

四、配置 MCP 客户端

在下列任一客户端的 MCP 配置里加入（把路径与密钥换成你的）：

  "mcpServers": {
    "image-studio": {
      "command": "node",
      "args": ["/absolute/path/to/github-image-json-new-api-https/mcp-server/dist/index.js"],
      "env": {
        "IMAGE_STUDIO_API_BASE": "https://image.tinchak0207.xyz/api/v1",
        "IMAGE_STUDIO_BIZ_KEY": "sk-biz-你的密钥"
      }
    }
  }

常用配置文件位置：

  • ~/Library/Application Support/Claude/claude_desktop_config.json
  • 项目根目录 .mcp.json

配置后重启客户端，agent 就能发现这 4 个工具。如果客户端要求绝对路径，请把args里的路径换成mcp-server/dist/index.js的绝对路径。

五、可用工具

  • list_models

    列出当前密钥可用的模型（图像 + 视频），含端点到单价的完整信息。

  • generate_image

    以 prompt 生成图片。内部会自动轮询任务直到完成，直接返回成品 URL。

  • generate_video

    以 prompt 生成视频。内部自动轮询直到完成，直接返回成品 URL。

  • get_image_task

    查询一个图像任务的当前状态（不等待完成）。

六、安全说明

  • 密钥只存在你本机的 MCP 配置里，不会上传给我们。
  • 生成走真实计费：agent 每次调用都按模型单价扣金币。
  • 密钥丢失只能重新签发，无法找回原文。

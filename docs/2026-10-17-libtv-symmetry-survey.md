# LibTV（liblib.tv）对称差勘察 — 2026-10-17

> 方法：登录态只读勘察（浏览器会话注入 + REA 证据化捕获 + 只读 API 抽查）。
> **本次未触发任何生成/付费调用**，全部为页面渲染与列表/权益类只读接口。
> 证据边界：未能进入付费后的会员页与具体成片工作流；服务端生成逻辑不可见（只观察客户端契约）。
>
> **与 2026-09-27 那份 API 级拆解的关系**：09-27 已从 chunk 里枚举出 ≈330 条端点、110 条 `tool_spec`、1299 个 skill 与 Remote MCP；
> 本报告不重复那层，只补**界面级结构**（入口同构、节点菜单、视频节点参数面、模型货架）与**当日定价快照**。
> 两者交叉处一致；不一致处已在文中标注（如"规格 53 条视频 vs 货架露出 27 个"）。

## 一、它的产品骨架（先看结构，不看功能清单）

1. **「五个生成入口」= 同一个 canvas 应用的五个节点类型。**
   视频/图片/音频/剧本/智能剪辑点击后全部跳到
   `https://www.liblib.tv/canvas?spaceId=<id>&projectId=<id>`，每次新建一个含对应节点的项目（视频节点/图片节点/音频节点/文本节点/智能剪辑节点）。
   → 它卖的**不是一个功能菜单，而是一张节点画布**；入口只是"预置好第一个节点的新建项目"。

2. **Agent 常驻在画布里，叫 TV Director。**
   画布右下角固定 agent 面板（"Agent 已升级为 TV Director：全流程成片规划、批量执行、创意脑暴、剧本创编"），
   以及独立路由 `/skill` 的技能市场。**Agent 不是独立产品，是画布的一个常驻组件。**

3. **节点菜单（画布 + 号）就是它全部创作能力的目录**：
   文本 / 图片 / 视频 / 智能剪辑(Beta) / 导演台(NEW) / 逐帧拉片 / SD 2.5 / 音频 / 脚本 / 素材库；
   资源入口：上传、从生成历史选择。

4. **视频节点是一个完整的"生成控制台"**（不是简单 prompt 框）：
   - 生成模式 5 种：文生视频 / 全能参考 / 图生视频 / 首尾帧 / 图片参考
   - 提示词附件 5 类：参考 / 标记 / 特效 / 角色库 / 运镜，prompt 里 `@引用素材`
   - 参数：比例（Auto/16:9/4:3/1:1/3:4/9:16/21:9）、清晰度（480P/720P/1080P/4K）、时长、生成音频（开/关）、生成数量（1/2/4）
   - 增值开关：**联网搜索、自动校验素材、智能引用 AutoLink**
   - 每次提交前展示**积分成本**（实测 `135`）
   - 模型选择器带 **ETA 与定位文案**（如 "Seedance 2.5 / 2min / 最强视频模型，全能参考，30s音画同步"）

5. **模型是一个"货架"，不是一个"聚合"**：视频模型实测 **27 个**，横跨 Seedance 2.5/2.5样片/2.0 VIP/2.0 Fast VIP/2.0 Mini、Wan 3.0/3.0 Prime/2.7/2.6/2.5/2.2、Kling O3/3.0 Turbo/3.0/O1/2.6/2.5/3.0动作迁移、Minimax H3/H3 Max、Hailuo 2.3/2.3 Fast/02、Vidu Q2/Q2 Pro/Q2 Turbo/Q3 Pro/Q4 Preview、Pixverse V5.5/V5、OmniHuman 1.5、Happy Horse 1.1/1.0、Style Video。
   每个都标了等待时长与能力差异（成本/质量/是否音画同步）。

6. **商业化是"会员阶梯 + 积分卡 + 按秒计价"三件套**：
   - 会员 6 档（L40 进阶 / L3 标准 / L4 高级 / L6 豪华 / L7 至尊），月/季/年三周期，¥66–¥3,569/月，随档位发 1,500–92,000 积分，并发 8/12/20/无限
   - 积分卡：¥1,099 / 1,899 / 6,999 / 16,999，对应 3万/5.5万/20万/50万积分，有效期 30 天/6 个月/2 年，且**按会员档位限购**
   - 按秒报价：首页 banner 直给 "Seedance 2.5 720P 有参 0.19 元/秒、无参 0.46 元/秒"
   - 非会员基线：每日 300 点生图算力、3GB 存储、VIP 模型与 LoRA 训练锁定

7. **增长是"赛事 + 学院 + 技能市场"三件套**：
   - `/activity`：赛事列表，奖池达 150 万现金 + 70 万积分（王者荣耀、蜜雪冰城、北京电影学院、优酷、Seedance 官方联名）
   - `/academy`：按功能索引的图文教程（逐帧拉片、音色克隆、智能续写、片段重拍、深度动作捕捉、音视频分离、3D 导演台、Blender 插件…）
   - `/skill`：**技能市场**——slash 命令（`/viral-video-replicator`、`/cinematic-shot-designer`、`/xingrannvpin`）+ 作者 + 使用量（2.7w/1.9w/8.8k）+ 一键"使用"

## 二、能力面对照（我方证据见各文件行号，来自只读清点）

| 维度 | LibTV | 我方（Image Studio） | 判定 |
|---|---|---|---|
| 画布 | 节点图 + 双击自由生成；10 类节点 | 12 类节点（含角色卡/场景卡/3D 导演台） | **我方更细，但缺"剪辑/脚本/素材库"节点** |
| 生成入口 | 5 入口同构 → 预置节点新项目 | 各页面独立（历史/画布分离） | 我方缺"一键起项目"的收敛入口 |
| 视频模型 | 27 个，含 Kling/Hailuo/Vidu/Pixverse/OmniHuman | 在售 6 个（seedance×4、minimax、agnes） | **明显缺口，供应链问题不是功能问题** |
| 首尾帧 | 一等公民（独立模式 + 快捷"首尾帧生成视频"） | 有映射，上游硬锁不保证（`last_frame_video_chain.ts:5`） | 部分，需选型/校准备案 |
| 参考体系 | 参考/标记/特效/角色库/运镜 五类附件 + `@引用` | 6 类参考角色 + 角色/场景卡 + identity/garment lock | **我方更强（锁定级），表达性弱于对方** |
| 智能剪辑 | 独立节点 + 4 模板（讲解/批量广告/口播/素材混剪） | 时间线（trim/split/speed/过渡/字幕/音频）+ 母带导出 | **我方能力强，缺"模板化入口"** |
| 逐帧拉片 | 独立节点 | `video_analyze` 场景切分 + VLM 反推 + 抽帧 | 能力有，未产品化为节点 |
| 导演台 | 3D 导演台 + Blender 插件 | 3D 导演台（director 节点 + cameraPresets） | 平（我方有，宣传面弱） |
| Agent | TV Director 常驻画布 | ~100 工具 + 确认闸 + 子代理（并发 3） | **我方更强（工具型 vs 聊天型）** |
| Skill | 公开市场：slash + 作者 + 使用量 + 一键使用 | 133 内建 + 私有自建，**明确无市集/作者/使用量** | **最大生态缺口** |
| 资产 | 生成历史 + 个人资产库 + 可灵资产库 | 生成历史 + 资产包/角色卡 + 项目资产库 | 平（对方多"厂商资产库"概念） |
| 项目 | 项目 + 文件夹 + 回收站 | 创作项目 + 画布项目，**无文件夹、无全局回收站** | 小缺口，易补 |
| 计费 | 6 档会员 × 3 周期 + 积分卡 + 按秒价 | 3 档金币包 + 首充 + 签到/邀请 + pro 订阅 SKU | **我方缺会员阶梯与按秒价** |
| 社区 | 创作精选作品流（可"查看创作过程"）+ 赛事 + 学院 | 静态官方案例 + 单作品分享/Remix，**无作品流/赛事/榜单** | **第二大生态缺口** |
| B 端 | 未见公开 API 商业面 | B 端 sk-biz API + 分层价 + 团队席位 | **我方独有护城河** |

## 三、值得抄的六个机制（按性价比排序）

1. **"五个入口 = 一个画布的五种新建项目"**（P0）
   不需要新做界面：把现有 `视频生成/图片生成/…` 落成"新建项目 + 预置节点"的同一个动作。
   证据：五次点击产出五条 `canvas?spaceId=…&projectId=…`，节点名与入口一一对应。

2. **模型货架带 ETA 与定位文案**（P0）
   模型选择器直接告诉用户"多久出、强在哪"，用户不需要试错。我方 catalog 已有 kind/比例/分辨率/币价，缺 ETA 与一句定位。

3. **提交前的成本展示**（P0）
   参数行末尾常驻 `135`（积分）。我方扣费在生成后才可见；改成选择器旁实时估价，直接消掉"生成完才发现贵"的投诉面。

4. **提示词附件化：参考/标记/特效/角色库/运镜 + `@引用`**（P1）
   把我们已有的 reference-image-roles、camera-motion-presets、character-cards 变成 prompt 里的结构化附件与 `@` 补全，而不是侧栏对话框。

5. **Skill 市场的"作者 + 使用量 + 一键使用"**（P1）
   这是它最便宜的护城河：不需要算法，只需要把 skill 变成有署名、有计数、可被复用的公开对象。
   我方现在明确禁止用户公开发布（`MySkillsDialog`），这条产品红线若要动，属于暴君裁量。

6. **赛事作为内容引擎**（P2）
   现金奖池 + 品牌联名（王者荣耀/蜜雪/北影/优酷）换的是作品供给与传播，不是功能。我方无赛事模型。

## 四、不该跟的

- **27 个视频模型的货架**：那是供应链宽度，不是产品能力；我方的模型目录 40+ 更宽，缺的是"视频侧在售 SKU"。跟它比数量会输在没有上游，应比"每个 SKU 的成片质量与单价"。
- **按秒计价**：对方单价低到 0.19 元/秒是因为自建算力与规模化；我方按积分核算是为了不亏，硬跟会打穿毛利。
- **无限并发（至尊档 -1）**：没有对应的队列与配额治理就是自杀。

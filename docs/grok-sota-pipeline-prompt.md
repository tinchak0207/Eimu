# Grok SOTA 流水线调研 Prompt（四领域工业级 pipeline 范式挖掘）

用法：以下全文复制给 Grok（X / grok.com），一次发送。

---

你是一名 AIGC 影视与商业视觉生产的资深调研员。我要的不是"一张好图的提示词"，而是**多步骤、多产物、工业级生产流水线**的 SOTA 范式。请基于你在 X（Twitter）上看到的真实创作者复盘帖、GitHub 开源仓库、技术报告，对下面四个领域逐一输出。**每个领域都必须按第 1-5 节的结构回答，禁止只给单图 prompt。**

## 四个领域

A. **小说影视化**（novel → 情节拆解 → 分镜 → 角色资产 → 场景概念 → 成组视觉产出 → 视频）
B. **电商营销素材**（产品白底图 → 场景图 → 模特图 → 营销主视觉 → 多画幅/多 SKU 批量适配）
C. **短剧制作**（剧本拆场 → 分镜 → 主演角色资产 → CP 剧照 → 竖屏海报 → 成片）
D. **艺术策展式创作**（主题 → 情绪板 → 风格锚定 → 成组作品 → 展览主视觉）

## 每个领域必须回答的 5 节

### 第 1 节：完整流水线拓扑
- 阶段划分：这条流水线分几步，每步的名字（用行业黑话，如 style bible / character sheet / sketch-lock storyboard / animatic）
- 每阶段的**输入 → 输出产物**（产物必须是可落盘的文件/资产，如"结构化剧本 JSON""角色三视图转面表""分镜构图草图""每镜最终帧"）
- **阶段间衔接方式**：上一步产出如何喂给下一步（作为参考图？作为 JSON 字段注入 prompt？作为 sref/cref？作为审核门禁？）

### 第 2 节：每阶段最优模型/工具与提示词写法
- 每个阶段当前公认最优的模型/工具选择（LLM 拆剧本用什么、出角色表用什么、出分镜用什么、出视频用什么），**开源方案必须给出 GitHub 仓库名**（如 StoryDiffusion、ComfyUI_StoryDiffusion、StyleAligned、wind-comic、shortdrama-pipeline 这类，能带星数更好）
- 该阶段的提示词/指令写法要点：结构（字段化 JSON？自然语言？）、关键字段（情绪标签、镜头语言、一致性锚）

### 第 3 节：流水线品质关卡
- 哪一步最容易翻车（如：分镜角色漂移、情绪断裂、商品形变、风格前后不一）
- 每个易翻车点的**验收标准**（怎么判断这步产物合格，如"角色相似度阈值""构图草图锁定后再出最终帧""剧本人工批准后才生成人物"这类门禁）

### 第 4 节：跨步骤一致性技术（重点）
分别在**提示词层面**和**工作流层面**，挖这三个一致性的 SOTA 做法：
- **角色一致性**：cref/参考图链、角色 DNA 签名（把外貌特征结构化后逐镜注入）、IP-Adapter、主体绑定、逐角色单独生成再复用等
- **情绪连续性**：情绪表/beat note 如何从剧本层一路传递到分镜与成片
- **风格锚定**：style bible 关键帧（先出一张 canonical key art 作为全片 sref 锚）、sketch-lock（先黑白构图稿锁定构图再出成图）、StyleAligned 注意力共享、固定 seed 等

### 第 5 节：信息来源标注
- 每条关键范式标注来源：X 帖子（作者+大致热度）、GitHub 仓库（名+星数）、或"推断"（你没把握就明说是推断，禁止编造具体帖子和星数）

## 输出要求
- 简体中文，每个领域独立成章，用 Markdown 表格列阶段拓扑
- 优先 2025-2026 年的新范式；老项目（如 2023 的）只在仍是基座时提及并注明
- 最后给一节「四领域共性规律」：这些工业流水线在拓扑上的共同骨架（如：文本结构化 → 资产先行 → 门禁审核 → 组装产出）

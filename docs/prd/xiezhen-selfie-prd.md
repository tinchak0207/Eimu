# PRD：一张自拍 → 一整套写真（Emu 写真馆）

状态：草案 v1（2026-09-28）｜决策人：暴君｜约束：**不改价、不加免费额度**（新人礼维持 5 张、¥9.9=100 币、首充 ¥7=300 币）

---

## 0. 一句话

上传一张自拍，选一个风格，一分钟拿到一套 **9 张、像你本人、能直接发小红书九宫格** 的写真。

## 1. 为什么是这个（第一性）

| 类型 | 内容 |
|---|---|
| FACT | 妙鸭相机（2023）靠 ¥9.9 一套 AI 写真拿到数以百万计的付费用户，是国内 C 端 AI 付费人数最大的品类，已验证有人付钱。 |
| FACT | 我们的 gpt-image-2 成本约 ¥0.005/张，售价 ¥0.099/张（在行情区间）；一套 9 张的成本 ¥0.045，按现价收 9 币。 |
| FACT | 网页注册者 22/28 从没发起过生成：空白 prompt 框对小白是作业。「上传一张自拍」不需要会写 prompt。 |
| INFERENCE | 写真是**用户自己会主动发**的内容（虚荣），每一套成品都是一条小红书九宫格，分发成本由用户承担。 |
| HYPOTHESIS（最大风险）| gpt-image-2 以自拍作参考时「像本人」的比例够高。**不成立，整个方向就不成立** → 第 0 期先验这一条。 |

## 2. 人性钥匙（human-nature-traffic）

| 环节 | 主钥匙 | 用在哪 |
|---|---|---|
| 产品本身 | **虚荣**（我也可以这么好看） | 成品要比本人好看、又一眼认得出是本人；这是唯一的品质标准 |
| 付费瞬间 | **虚荣 + 贪婪** | 用户看到自己的第一张好看的图时付费；对比锚点是「影楼拍一套要几百上千」（对准处境，不贬低任何人群） |
| 用户分享 | **虚荣** | 九宫格一键导出，配文替用户写好（第一人称、零品牌） |
| 我方分发 | **好奇 + 懒惰** | 「一张自拍 → 九张写真」的前后对比；标题「【人麻了】一张自拍被AI拍成了写真」 |

反广告铁律落到产品上：导出的图**不放 Emu 大 logo**。只放法规要求的「AI生成」小角标，并在旁边加小字「Emu」，这是品牌唯一的露出位置。

## 3. 目标用户与场景

- **主**：18–30 岁女性，小红书重度用户，想换头像或发一组好看的照片，不想（或没钱、没时间）去影楼。
- **次**：需要职业形象照、证件照的求职者和打工人（实用刚需，付费意愿稳定）。
- **不做**：未成年人、他人照片（仅限本人或已获同意）、裸露或性感擦边内容。

## 4. 核心流程（手机优先）

```
落地 /xiezhen
  └ 首屏：6 张真实成品对比图（自拍 → 写真）＋ 一个按钮「上传自拍，试拍一张」
      └ 登入（沿用 OAuth；未登入时先暂存意图，登入后自动续上 → 复用 stashBlockedSend 那一格）
          └ 上传 1 张自拍（正脸清晰检查：人脸数=1、够大、不糊；不合格当场讲清楚原因）
              └ 选风格（首发 4 套，见 §6）
                  └ 试拍：先出 1 张（扣 1 币，新人礼可付）→ 约 40 秒
                      └ 结果页：大图 ＋「像不像？」
                          ├ 像 → 「拍完整套 9 张（再扣 8 币）」→ 余额不足 → 首充卡（¥7 得 300 币 = 33 套）
                          └ 不像 → 免费重拍 1 次（不扣币）→ 仍不像 → 提示「换一张更清晰的正脸自拍」
                              └ 整套完成 → 九宫格预览 → 「保存九宫格」「生成小红书配文」「分享链接（带邀请）」
```

说明：
- 新人礼 5 币 = 试拍 1 张 + 还能再试 4 张 / 4 个风格，**不够拍一整套**。付费点就落在「看到自己好看、想要整套」的那一刻，额度不用加。
- 付费点上用的是现有的首充卡（¥7 得 300 币），不另设新价目。

## 5. 品质保证（决定生死）

1. **只为像本人的图收费**：每张图出来后，用视觉模型比对「是不是同一个人」＋「有没有崩脸／多指／字迹」，不过就在内部重拍，最多 2 次。内部重拍成本约 ¥0.01，由我们吸收；用户只为交付的图付费（沿用现有的失败退币语义，**单价不变**）。
2. **参考图只保留五官辨识度**（nuyoah-xiezhen 原则 2）：妆容、发型、服装、场景、光线都由风格接管，否则成品只是「自拍加滤镜」。
3. **系列一致、每张不同**（nuyoah-xiezhen 原则 5）：每套固定「整体风格词链＋成像机制词链」，9 张各自重新设计构图、动作、景别（特写 3 张、半身 4 张、全身 2 张），九宫格才有节奏。
4. **皮肤质感**（nuyoah-xiezhen 原则 8）：按景别控制反光，默认自然半哑光或克制缎光，避免全脸油膜和塑胶皮。
5. 画幅 3:4（小红书原生），1024×1365 左右，以模型实际支援的尺寸为准。

## 6. 首发 4 套风格（每套 = 系列母版 + 9 个变体，用 nuyoah-xiezhen-prompt 产出）

| 风格 | 为什么选 | 主要情绪 |
|---|---|---|
| 胶片直闪 | 小红书长青热门，最有「随手拍很好看」的原生感 | 虚荣 |
| 韩系证件照／职业形象照 | 刚需、影楼价格锚点最清楚 | 贪婪 |
| 港风复古 | 辨识度高、九宫格效果强 | 虚荣＋好奇 |
| 新中式古风 | 平台季节性爆款，对比反差大 | 好奇 |

二次元形象（PixAI，成本 0）、情侣／闺蜜双人照放第 2 期：参考图一致性要另外验证。

## 7. 分享与增长回路

- **保存九宫格**：一张 3×3 拼图＋9 张单图，每张右下角「AI生成 · Emu」小字（法规标识兼品牌位）。
- **生成小红书配文**：按 human-nature-traffic 的标题公式写，≤18 字、第一人称、零品牌，例如「一张自拍被AI拍成了写真」；品牌只出现在最后一行标签。用户可改。
- **分享链接**：沿用 `/p/[shareId]`（已带分享者的邀请码）。新增「整套」分享页：看的人点「我也拍一套」→ 落到 /xiezhen 并预选同一个风格。
- 邀请奖励沿用已上线口径（好友出第一张图，双方到帐）。

## 8. 合规与隐私（上线前必须全部到位）

- 显式标识：每张导出图都带「AI生成」角标；隐式标识：写入 metadata（《人工智能生成合成内容标识办法》，2025-09-01 起施行）。
- 上传页勾选「这是我本人或已获本人同意；我已满 18 岁」，不勾不能上传。
- 自拍原图只用于本次生成，**7 天后自动删除**，不公开、不做任何训练；成品默认私有，分享要用户主动操作。
- 内容闸：拒绝儿童脸、裸露和性感擦边请求；检测到多张脸或疑似名人时拒绝，并讲明原因。

北极星：**每周付费用户数**。

# PRD：一張自拍 → 一整套寫真（Emu 寫真館）

狀態：草案 v1（2026-09-28）｜決策人：暴君｜約束：**不改價、不加免費額度**（新人禮維持 5 張、¥9.9=100 幣、首充 ¥7=300 幣）

---

## 0. 一句話

上傳一張自拍，選一個風格，一分鐘拿到一套 **9 張、像你本人、能直接發小紅書九宮格** 的寫真。

## 1. 為什麼是這個（第一性）

| 類型 | 內容 |
|---|---|
| FACT | 妙鴨相機（2023）靠 ¥9.9 一套 AI 寫真拿到數以百萬計的付費用戶，是國內 C 端 AI 付費人數最大的品類，已驗證有人付錢。 |
| FACT | 我們的 gpt-image-2 成本約 ¥0.005/張，售價 ¥0.099/張（在行情區間）；一套 9 張的成本 ¥0.045，按現價收 9 幣。 |
| FACT | 網頁註冊者 22/28 從沒發起過生成：空白 prompt 框對小白是作業。「上傳一張自拍」不需要會寫 prompt。 |
| INFERENCE | 寫真是**用戶自己會主動發**的內容（虛榮），每一套成品都是一條小紅書九宮格，分發成本由用戶承擔。 |
| HYPOTHESIS（最大風險）| gpt-image-2 以自拍作參考時「像本人」的比例夠高。**不成立，整個方向就不成立** → 第 0 期先驗這一條。 |

## 2. 人性鑰匙（human-nature-traffic）

| 環節 | 主鑰匙 | 用在哪 |
|---|---|---|
| 產品本身 | **虛榮**（我也可以這麼好看） | 成品要比本人好看、又一眼認得出是本人；這是唯一的品質標準 |
| 付費瞬間 | **虛榮 + 貪婪** | 用戶看到自己的第一張好看的圖時付費；對比錨點是「影樓拍一套要幾百上千」（對準處境，不貶低任何人群） |
| 用戶分享 | **虛榮** | 九宮格一鍵導出，配文替用戶寫好（第一人稱、零品牌） |
| 我方分發 | **好奇 + 懶惰** | 「一張自拍 → 九張寫真」的前後對比；標題「【人麻了】一張自拍被AI拍成了写真」 |

反廣告鐵律落到產品上：導出的圖**不放 Emu 大 logo**。只放法規要求的「AI生成」小角標，並在旁邊加小字「Emu」，這是品牌唯一的露出位置。

## 3. 目標用戶與場景

- **主**：18–30 歲女性，小紅書重度用戶，想換頭像或發一組好看的照片，不想（或沒錢、沒時間）去影樓。
- **次**：需要職業形象照、證件照的求職者和打工人（實用剛需，付費意願穩定）。
- **不做**：未成年人、他人照片（僅限本人或已獲同意）、裸露或性感擦邊內容。

## 4. 核心流程（手機優先）

```
落地 /xiezhen
  └ 首屏：6 張真實成品對比圖（自拍 → 寫真）＋ 一個按鈕「上传自拍，试拍一张」
      └ 登入（沿用 OAuth；未登入時先暫存意圖，登入後自動續上 → 複用 stashBlockedSend 那一格）
          └ 上傳 1 張自拍（正臉清晰檢查：人臉數=1、夠大、不糊；不合格當場講清楚原因）
              └ 選風格（首發 4 套，見 §6）
                  └ 試拍：先出 1 張（扣 1 幣，新人禮可付）→ 約 40 秒
                      └ 結果頁：大圖 ＋「像不像？」
                          ├ 像 → 「拍完整套 9 张（再扣 8 币）」→ 餘額不足 → 首充卡（¥7 得 300 币 = 33 套）
                          └ 不像 → 免費重拍 1 次（不扣幣）→ 仍不像 → 提示「换一张更清晰的正脸自拍」
                              └ 整套完成 → 九宮格預覽 → 「保存九宫格」「生成小红书配文」「分享链接（带邀请）」
```

說明：
- 新人禮 5 幣 = 試拍 1 張 + 還能再試 4 張 / 4 個風格，**不夠拍一整套**。付費點就落在「看到自己好看、想要整套」的那一刻，額度不用加。
- 付費點上用的是現有的首充卡（¥7 得 300 幣），不另設新價目。

## 5. 品質保證（決定生死）

1. **只為像本人的圖收費**：每張圖出來後，用視覺模型比對「是不是同一個人」＋「有沒有崩臉／多指／字跡」，不過就在內部重拍，最多 2 次。內部重拍成本約 ¥0.01，由我們吸收；用戶只為交付的圖付費（沿用現有的失敗退幣語義，**單價不變**）。
2. **參考圖只保留五官辨識度**（nuyoah-xiezhen 原則 2）：妝容、髮型、服裝、場景、光線都由風格接管，否則成品只是「自拍加濾鏡」。
3. **系列一致、每張不同**（nuyoah-xiezhen 原則 5）：每套固定「整體風格詞鏈＋成像機制詞鏈」，9 張各自重新設計構圖、動作、景別（特寫 3 張、半身 4 張、全身 2 張），九宮格才有節奏。
4. **皮膚質感**（nuyoah-xiezhen 原則 8）：按景別控制反光，默認自然半啞光或克制緞光，避免全臉油膜和塑膠皮。
5. 畫幅 3:4（小紅書原生），1024×1365 左右，以模型實際支援的尺寸為準。

## 6. 首發 4 套風格（每套 = 系列母版 + 9 個變體，用 nuyoah-xiezhen-prompt 產出）

| 風格 | 為什麼選 | 主要情緒 |
|---|---|---|
| 胶片直闪 | 小紅書長青熱門，最有「隨手拍很好看」的原生感 | 虛榮 |
| 韩系证件照／职业形象照 | 剛需、影樓價格錨點最清楚 | 貪婪 |
| 港风复古 | 辨識度高、九宮格效果強 | 虛榮＋好奇 |
| 新中式古风 | 平台季節性爆款，對比反差大 | 好奇 |

二次元形象（PixAI，成本 0）、情侶／閨蜜雙人照放第 2 期：參考圖一致性要另外驗證。

## 7. 分享與增長迴路

- **保存九宫格**：一張 3×3 拼圖＋9 張單圖，每張右下角「AI生成 · Emu」小字（法規標識兼品牌位）。
- **生成小红书配文**：按 human-nature-traffic 的標題公式寫，≤18 字、第一人稱、零品牌，例如「一张自拍被AI拍成了写真」；品牌只出現在最後一行標籤。用戶可改。
- **分享鏈接**：沿用 `/p/[shareId]`（已帶分享者的邀請碼）。新增「整套」分享頁：看的人點「我也拍一套」→ 落到 /xiezhen 並預選同一個風格。
- 邀請獎勵沿用已上線口徑（好友出第一張圖，雙方到帳）。

## 8. 合規與隱私（上線前必須全部到位）

- 顯式標識：每張導出圖都帶「AI生成」角標；隱式標識：寫入 metadata（《人工智能生成合成内容标识办法》，2025-09-01 起施行）。
- 上傳頁勾選「这是我本人或已获本人同意；我已满 18 岁」，不勾不能上傳。
- 自拍原圖只用於本次生成，**7 天後自動刪除**，不公開、不做任何訓練；成品默認私有，分享要用戶主動操作。
- 內容閘：拒絕兒童臉、裸露和性感擦邊請求；檢測到多張臉或疑似名人時拒絕，並講明原因。

- `select='gt(scene,0.35)'`：**0 个切点**；`0.25`：6 个（3.33/11.57/14.40/19.30/26.53/29.03），目检多数为剑气闪光或前景遮挡，并非硬切。

## 5. 场景/地形/光照要素
- 地形：起伏平缓的大草原，前景高草（有风吹动），中景零星樱花树（粉色团状，5–8 棵可见），远景连绵低山/丘陵带薄雾
- 天空：大面积积云，云隙透光；大招时天空出现粉色巨型符阵
- 光照：侧逆光暖阳（太阳在画左上/后方），**体积光/God rays** 穿云，人物轮廓光明显；大招段整体粉色泛光（bloom）
- 后段场景切换：26.5s 后地面变成**樱花花海**（粉花铺地），29.4s 回到绿草原
- 色调主色：草绿 #5f7a3a 系 + 樱粉 #f2a5c8 系 + 主角红/金黄 + 天空灰蓝/暖白；恶魔深灰紫黑
- 角色：主角红衣黄裙、长黑发束马尾、单手长剑；敌人为长角恶魔（人形巨体，灰黑带紫），数量从 2 只到 20+ 群敌
- 粒子：贯穿全片的樱花花瓣（风向左→右），剑气粉色半透明弧带，命中时花瓣爆散

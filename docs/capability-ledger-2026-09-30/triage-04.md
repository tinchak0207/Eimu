## 突出亮点 Top 10

1. **骨架富化：一句话长出整张产线图** — 一句需求自动衍生成含工具卡／配方卡／门禁卡的 81 节点产线图；用户感知是「讲一句话，整条生产线自己长出来」，竞品罕见。
2. **行内实体引用 `@[种类:名称]`（画布＋B端＋胶囊渲染）** — 在提示词里直接引用角色／场景／道具卡，就地展开成 prompt 片段与参考图，且渲染成带微缩图胶囊；把「素材库」变成可写进句子的语言。
3. **生成血统（lineage）与血统抽屉** — 每张生成物都可追溯来源（衍生／引用／再来 N 组），用户可在抽屉看清脉络；这是「可回溯的创作资产」能力，不是正确性。
4. **回合中追加指引（steer）** — 助理跑到一半还能补话而不中断回合；用户感知为「不用等它跑完、能当场改方向」。
5. **模板自动落卡** — 产线跑完自动生成角色三视图／场景／选角等实体卡并就地聚合；用户感知为「跑完自动攒出自己的素材库」。
6. **「重试中（x/N）」与黏性渠道** — 上游抖动不再丢丑错误，且成功的模型被钉住让后续对话稳定；用户感知为「它会自己撑过去」。
7. **五值实体卡与变体卡** — 角色／场景／风格／道具／音频五种卡＋指定母卡的变体；把素材体系从单一角色扩成完整资产分类。
8. **B 端参考图输入 `reference_images`** — API 直接带最多 5 张参考图并可标 role，让 API 客户能做出参考图生图产品。
9. **团队成员点数配额 `/v1/team/quota`** — 团队主帐可划／收成员额度（绝对目标值、失败回滚）；企业向的配额治理能力。
10. **客户可见余额权威帐本** — 余额＝永久池＋订阅池可用额、过期当场判定、欠费可为负不粉饰；对外口径从「帐面净额」变成真实可用余额。

## 突出亮點 Top 10

1. **3D 導演台與 Blender 生成管線（含機位語言、GLTF 節點卡、零 token 資產復用）** — 業界少見：把 Blender 當一等生成上游、鏡頭軌跡直接下生成指令、資產指紋命中不花額度；用戶感知「3D 真的會動且不燒錢」。
2. **一句話需求展開整張產線圖（workflow DSL ↔ 畫布雙向編譯）＋ 模板 pipeline 自動鋪泳道** — 用戶寫一段筆記就得到一條帶門禁的多步產線，且可反編譯回文字，是可視化生產線的核心賣點。
3. **短劇配方五段管線（大綱→選角→美術→劇本→分鏡一段式）** — 一個垂直題材從零到分鏡的完整自動化，且「能算的不讓模型猜」（分鏡秒數按語速折算），交付物直接可用。
4. **7 位 MOE 專家軍團** — 內建七個領域專家（導演／音樂／影片／剪輯／編劇／動效／Web3D），用戶感知「助理真的懂這個行業」。
5. **音樂確定性規則層＋通路感知（六層公式、220 runes 預算、FlowMusic 邊界實測）** — 用規則保證音樂提示詞品質與不超限，且不同上游各按其實際行為處理，使用者得到穩定可用的音樂。
6. **免登入免費提示詞優化端點（六槽結構化輸出）** — 不註冊就能體驗核心能力，是明確的增長漏斗鉤子。
7. **歷史「再來 N 組／微調變體」批量重跑 ＋ 歷史一鍵存角色卡** — 一鍵把舊配方複用重跑 1/2/3/5/8 組、只改一個變量，且可延伸成角色卡，複用性極高。
8. **模板庫＋旋轉木馬＋點卡即鋪畫布** — 模板不只展示，點一下就注入提示詞並鋪好整條工作流，還可 undo；入口本身是有物理手感的輪播。
9. **帳號池 402 自動切號與供應商 24/7 自愈** — 上游額度／故障自動吸收，用戶端不中斷，屬於「可用性斷路器」級的體驗保障。
10. **PWA 跨瀏覽器登入 handoff ＋ GitHub 一鍵授權自動簽發 B 端金鑰** — 解決 PWA 獨立儲存無法登入的硬問題，且插件端授權即自動開通 API 金鑰，兩段都直接影響轉化。

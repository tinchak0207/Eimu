## 突出亮点 Top 10

1. **3D 导演台与 Blender 生成管线（含机位语言、GLTF 节点卡、零 token 资产复用）** — 业界少见：把 Blender 当一等生成上游、镜头轨迹直接下生成指令、资产指纹命中不花额度；用户感知「3D 真的会动且不烧钱」。
2. **一句话需求展开整张产线图（workflow DSL ↔ 画布双向编译）＋ 模板 pipeline 自动铺泳道** — 用户写一段笔记就得到一条带门禁的多步产线，且可反编译回文字，是可视化生产线的核心卖点。
3. **短剧配方五段管线（大纲→选角→美术→剧本→分镜一段式）** — 一个垂直题材从零到分镜的完整自动化，且「能算的不让模型猜」（分镜秒数按语速折算），交付物直接可用。
4. **7 位 MOE 专家军团** — 内建七个领域专家（导演／音乐／影片／剪辑／编剧／动效／Web3D），用户感知「助理真的懂这个行业」。
5. **音乐确定性规则层＋通路感知（六层公式、220 runes 预算、FlowMusic 边界实测）** — 用规则保证音乐提示词品质与不超限，且不同上游各按其实际行为处理，使用者得到稳定可用的音乐。
6. **免登入免费提示词优化端点（六槽结构化输出）** — 不注册就能体验核心能力，是明确的增长漏斗钩子。
7. **历史「再来 N 组／微调变体」批量重跑 ＋ 历史一键存角色卡** — 一键把旧配方复用重跑 1/2/3/5/8 组、只改一个变量，且可延伸成角色卡，复用性极高。
8. **模板库＋旋转木马＋点卡即铺画布** — 模板不只展示，点一下就注入提示词并铺好整条工作流，还可 undo；入口本身是有物理手感的轮播。
9. **帐号池 402 自动切号与供应商 24/7 自愈** — 上游额度／故障自动吸收，用户端不中断，属于「可用性断路器」级的体验保障。
10. **PWA 跨浏览器登入 handoff ＋ GitHub 一键授权自动签发 B 端金钥** — 解决 PWA 独立储存无法登入的硬问题，且插件端授权即自动开通 API 金钥，两段都直接影响转化。

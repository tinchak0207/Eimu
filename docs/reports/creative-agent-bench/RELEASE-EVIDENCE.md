## 三条结论，三种证据

| 想证明什么 | 有效证据 | 不能替代它的材料 |
|---|---|---|
| 自主完成音乐创作 | 短需求→Agent实际决策/创作内容→真实工具执行→可播放最终音频；保留人工介入和失败 | 流程图、工具存在、成熟brief直送、作品高分 |
| 特定作品的音乐品质 | 原始音频、版本/预处理一致的量表结果；人工盲听单独记录 | “预测分=专业听者真值”“超过获奖音乐” |
| harness净增益 | 同模型版本、原始输入、预算与采样/选择机会下实际运行对照 | 底模成绩、不同产品排名、只给我方best-of-N |

SOTA产品横比回答“用户选哪个产品更能满足同一需求”，可以包含产品实际使用的不同底模；它不能直接归因为我方harness。未测出差异不证明无效；更强底模或局部模式结果不能由传递性推导未运行模式。

## 原评估器研究的具体补正（2026-10-06）

- [SongEval原论文 §4.1](https://arxiv.org/html/2505.10793v1)：2399首中随机2199训练、200评估，并加50首真实歌曲。旧[校准报告](../music-bench/REPORT.md)与记忆却按 `range(0,2399,60)` 抽40首；未核官方训练/评估名单，不能标“独立留出”。人工标签本身是模型训练目标；它和预测值相关不能排除训练重叠。尚未证明实际泄漏，也不能证明独立泛化；撤回“4.5就是专业听者4.5”和“我方真人p90”。
- 时长核查：本轮比较40首 `calib_src/*.mp3` 与 `calib_short|calib_long/*.wav`，没有超过0.1秒的时长差；short/long是按时长分组，未见该批裁段。SongEval官方eval.py送整曲音频到MuQ；把长曲截成短段再评分会改变结构/连贯性观测，不可自动等价整曲。此核查没有重跑评分，也未证明其他批次所有输入无裁段。
- [SongBench原论文 §2.1/§2.3/§3.1](https://arxiv.org/html/2604.25937v1)明确数据含真实版权歌曲，训练/ID测试95:5；另352条来自外部模型作OOD。旧“人类商业母带一律OOD”的解释错误；特定获奖曲参考集是否重叠训练未知。相关系数区分逐曲与系统均值，不能拿系统层相关替单曲保证。
- [SongBench许可](https://github.com/Tencent/SongBench/blob/main/LICENSE.txt)限制工具学术用途，禁商业/生产使用。[SongEval LICENSE](https://raw.githubusercontent.com/ASLP-lab/SongEval/main/LICENSE)写Apache2.0，而[工具README](https://github.com/ASLP-lab/SongEval#-license)与[数据卡](https://huggingface.co/datasets/ASLP-lab/SongEval/blob/main/README.md)写CC BY-NC-SA4.0，存在需要澄清的资源与文档冲突。不能宣称整个工具已无商业限制，也不未经核实泛化成“每个派生分数绝对不能引用”；本轮不新调用评分器、不新增商业评分图。

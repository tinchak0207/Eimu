# /pricing 方案卡 3D 化：創作簡報（提示詞）

> 本檔由需求澄清訪談產出，共 7 輪 28 問。每一條都是暴君的原話裁定，不是執行者的推測。
> 標記 `【推斷】` 的條目是從相鄰答案推導的，執行前若與現場衝突，以現場為準並回報。
> 標記 `【執行者裁定】` 的條目是刻意留白——暴君不負責視覺，這些由執行者自由決定。

---

## 0. 一句話目標

把 `/pricing` 的四張方案卡（梦芽 / 梦影 / 梦虹 / 自訂）從「文字報額度」變成 **在真實家具場景上絲滑落下的 3D 玻璃作品卡堆**，讓額度變成可觸摸、可互動的實體，看的人第一眼冒出的念頭是「創作要井噴了」。

---

## 1. 靈魂（不可談判的四條）

### 1.1 第一眼的情緒 = 「創作要井噴了」
不是「這網站技術好強」、不是「這很貴」、不是「這是一疊庫存」。
要的是**作品不斷湧出來、看了就想立刻動手畫、滿屏都是可能性**的興奮感。
所有節奏、光線、密度決策都服務這一句。

### 1.2 觀眾站在桌邊，不是隔著櫥窗
參與者，不是旁觀者。手伸得進去，東西已經是他的，可以隨便摸。
不做「隔一層精緻薄膜」的距離感，不做美術館式的展示台。

### 1.3 「額度很多」＝ 滿，溢出鏡頭
越大量級越失控：從看得見桌面，到鋪滿桌面，到滿到溢出鏡頭邊緣、蓋掉一部分視線。
豐盛到奢侈，甚至有點暴發。**不是**安全感的囤貨、**不是**流水線的效率感、**不是**省制的高級感。

### 1.4 liquid glass 的角色 = 只有光
玻璃質感**只活在邊緣與光線掠過的地方**，物件本身是實的。木頭就是木頭，玻璃卡像寶石躺在真家具上。
- ❌ 不要「裡外都是玻璃、沒有內外之分」的未來感／夢境感
- ❌ 不要「隔在你與世界之間的一層薄膜」的介面感
- ✅ 要的是**真實產品攝影**的質感：實物 + 掠過表面的高光

### 1.5 「絲滑」的定義 = 電影感，物理聽導演的
該快就快、該慢就慢、允許違反重力的瞬間懸停。
**這不是物理引擎 demo，是剪好的廣告片。** 物理為戲劇性服務。

## 2. 四檔的世界

| 檔位 | 價格 / 額度 | 場景 | 光 |
|---|---|---|---|
| 梦芽 | ¥9.9 / 100 金幣 | 小木托盤 | 晨光初現的窗台 |
| 梦影 | ¥29.9 / 500 金幣（現有預設檔） | 寫字桌 | 夜燈下的書桌 |
| 梦虹 | ¥69 / 1500 金幣 / 90 天 | 大工作台（帶抽屜、參考書） | 雨後天光的工作室 |
| 自訂 | 2,000–1,000,000 金幣（0.045 RMB/金幣） | 天亮之後的工作室，**無邊界**（額度無上限 → 空間無限延伸） | 天亮 |

**「夢」的敘事要延續進場景**：三档合起來是一個夜的故事（晨 → 夜 → 天光）。
自訂檔是這條敘事的終點：天亮之後。

**場景隨量級放大**：量級越大，場景越大、越滿、越失控。

**四個世界硬剪接**：切換档位時不做空間連貫轉場，就是電影式的場景切接。每一档可以有自己的機位與光線。

**四档製作投入平等**：不分主次，每一档輪流當主角時都一樣猛。沒有「這档是配角所以做簡單一點」。

## 3. 主角制與配角

- **一次只有一張卡當主角**，其他卡淡出（淡出淡入實現）。
- 淡出後，其他卡**縮成底部選片條**（像選片條），觀眾仍然知道「一共有四档可選」。
- **環與選片條是同一批卡**：拖曳時它們在環上轉動（看得到三維空間排列），停下來後非主角卡淡出並縮成底部選片條。兩者是同一個機制的兩個狀態，不是兩套 UI。
- 進 `/pricing` 第一眼停在**梦影**（現有預設 `popular`），不是最猛的梦虹。
- 主角卡**真的衝出卡框**，但**只在 `/pricing` 內容區內溢出**：可以壓到旁邊的空白與鄰卡原本的位置，**不越過 navbar、不壓到頁尾**。

## 4. 卡片本體

- **玻璃基 + 卡面貼真實生成圖**。卡面是站內 `public/showcase` 素材（`【推斷】` 一疊 50 張是混裝、每張不同，不是同款重複）。
- **全類型混裝**：人物 / 場景 / 產品 / 概念均勻混，展示「平台什麼都能做」。
  - 不是只挑與用戶同類的圖（犧牲認同感換廣度，這是刻意選擇）
  - 不是只挑最好看的那幾張
- **3D 滿版填滿整張卡，拆掉外層 `.lg-card` 玻璃殼**。玻璃質感改由 3D 材質與掠過的光提供。
- **卡面只留價格與支付 CTA**，額度文字（「約 100 張 GPT Image 2（1K）」「500 金幣通用額度」）全部從卡面刪掉。
- **價格與支付書是浮在 3D 場景之上的玻璃層**（DOM），像手機 UI 浮在相機預覽上——不是印在桌面上。
- 卡面比例白名單先前已改過（桌面 0.82、手機 1.45），`【執行者裁定】` 是否需要隨 3D 化再調。

## 5. 數量怎麼說話（密度隱喻）

- 用**堆高與厚度軸**：實體卡數不必與真實張數一對一。堆高、厚度、溢出程度是量級的函數。
- 硬要求：**100 與 1500 一眼要能分辨**。
- 實體卡的具體數量、堆高與厚度的對應曲線 → `【執行者裁定】`。
- 自訂檔滑桿拖動時：**先伸縮、最後才落**——拖的過程中卡堆在原地平滑伸縮，鬆手落定才真的掉一輪。不是持續補落，也不是每次拖動都整堆重落（這兩者會眩）。

## 6. 互動（四種全要）

1. **拖曳撥動卡片**：像真的摸一疊卡，有慣性與摩擦，可推倒 / 撥散 / 翻面。
2. **hover 拾起單張**：**純觸感，不說話**——卡片被拾起、翻轉、在光下轉一圈。**不顯示任何資訊文字**（不寫「這張 = 1 張圖」，不計數，不報模型）。
3. **滑桿即時增減**（自訂檔）：見 §5「先伸縮、最後才落」。
4. **點擊卡片回饋**：彈跳 / 翻轉 / 微光，純觸感，不承載資訊。

**進場掉落**：卡片一進螢幕自動全部落下 + 彈跳沉降（約 2–4 秒），之後靜置等互動；切換档位時重掉一次。

**聲音**：**要，而且要隨互動而生**（不是只有進場落卡那一次）。
材質 = **清脆玻璃相碰的輕盈叮噹 + 落在硬木桌面的輕得**。音量小、像環境音，但有它沒它是兩個世界。
具體取樣與音量 → `【執行者裁定】`。

---

## 7. 物件與邊界

**只動這四張方案卡**（含自訂檔）。以下結構**不動**：
- 邀請獎勵玻璃條
- 模型價格表（`modelPriceRows`）——**額度文字從卡面拿掉後，這裡仍是額度資訊的落點，不得同時拿掉**
- 兌換碼區塊
- FAQ

**但整頁氛圍一起提**：背景、光線、滾動節奏要與四張卡同屬一個世界，讓整頁像一個空間，不是「一個 3D 元件被放在普通卡片頁上」。

---

## 8. 對誰說話

對象是**已在用 AI 生圖、正在到處比價的人**。
重點是量與性價比，畫面要敞亮、有火力。
**不是**給不懂 AI 的新手看的（不需要引導與親切感），**不是**給要工業吞吐量的專業工作室看的（不需要冷硬的儀表板感）。

## 9. 犧牲與紅線

### 已接受
- ✅ 一次只看一档（想看完整四檔得一張一張切）
- ✅ 手機降級（卡片數減少、音效可選、效果打折），完整體驗留給桌面
- ✅ 這一頁會變得與站內其他頁面風格不一致，像一個獨立作品

### 不可接受（紅線）
- ❌ **不接受載入變慢**。
  **進 `/pricing` 不能等。首屏必須即刻可見**：3D 必須漸進增強（先能看見，再接管），**不得用 loading 遮罩或全螢幕等待畫面**。
  這條是他唯一沒勾的犧牲項，等於最高優先的效能約束。

## 10. 必須沿用、不可動

- **`PricingPlanCarousel` 的環形幾何、手勢、吸附、彈簧**（這是從 `AgentTemplateCarousel` 逐行複製來的，白名單以外的物理參數一行不許動；`【執行者裁定】` 僅吸附參數為戲劇性可微調）。
- **全部換算數字仍由計價 catalog 驅動**：`usePricingRevision()` 訂閱，admin 改價 → 頁面重渲，展示永不脫鉤。
- **`PLANS` 三檔靜態數據、`customPlanPrice()` 單價權威**不動（0.045 RMB/金幣，禁在路由/元件手寫單價）。
- 白名單①（數據源）仍是 `plans` + `customPlanFor()`；白名單②（卡面渲染）是本專案的改動範圍。
- 設計權威：`design-system/MASTER.md` + `DESIGN.md` + `tailwind.config.ts`（`lg-*` 體系，正文 ≥ 13px）。

## 12. 驗收判準（感覺導向，不是功能清單）

逐條問「是不是」，不是問「有沒有做」：

1. 第一眼三秒，看的人心裡冒出的是「**創作要井噴了**」（興奮），而不是「這網站技術好強」？
2. 有沒有「**站在桌邊、手伸得進去**」的感覺（不看說明就知道可以摸）？還是隔著一層東西在旁觀？
3. 100 與 1500 **一眼分得出**嗎（滿的程度）？
4. liquid glass 是否**只出現在光掠過的地方**、物件本身是實的？還是整個畫面飄著一層玻璃霧？
5. 物理是否**聽導演的**（有非物理的懸停與加速），而不是物理引擎 demo？
6. 進 `/pricing` **有沒有任何等待**？
7. 「夢」的夜的故事（晨光 → 夜燈 → 天光）有沒有真的在三個場景裡讀得出來？
8. 四档輪流當主角時，**有沒有任何一档看起來是配角**？

## 13. 執行者自行裁定清單（刻意留白）

- WebGL context 預算、每張卡在什麼狀態下渲染、fps 偵測與降級門檻
- 具體光源色溫、機位、焦距、景深
- 實體卡數的具體值與堆高／厚度曲線
- 音效取樣、音量、混音
- 是否保留現有 `highlight: true`（梦影）的視覺權重
- 吸附／彈簧參數的戲劇性微調幅度
- 自訂檔滑桿控件在 3D 之上的落位方式
- `@react-three/fiber` 引入與否
- 卡面比例是否隨 3D 化再調

## 14. 尚未裁定（需暴君點頭）

1. **hover 拾起「純觸感、不說話」與卡面只留價格**這兩條合起來，意味著額度資訊只由卡片實體數量與堆高表達。若之後覺得「看半天不知道是 100 張還是 1500 張」，需要回頭補一個極簡角標——目前是刻意不給。
2. **底部選片條與環是同一批卡**（本檔採此解讀）。若執行時發現「配角同時要淡出、又要轉動、又要縮成選片條」在環形幾何上打架，回報而不是自行改設計。

# 吞并决策总清单（2026-08-25，11 卷竞品侦察 × PM 对称差框架）

> 框架：吞什么／什么姿势吞（【深化】=对手浅层特化→我们的一般化机制；【吸收】=独立能力→工作台一等公民、入口统一；【不吞】=与 General 定位冲突）。铁律：全部挂现有 owner，零新系统零新入口；特化一律以参数化/profile 进入。证据见各卷侦察报告（会话存档）。

## 主线一：配方资产总线（7 卷独立汇合，第一排期）

**吞并对象**：即梦/Liblib 做同款、Civitai 工作流下载、MJ --r/Vary、MJ --sref、workflow-png 导入、Krea 会话→pipeline、Lovart 模板橱窗。

**统一机制**：规范化「配方」对象 = workflow-recall payload（六槽 prompt＋模型 id＋尺寸＋参考图角色＋区域 prompt＋角色卡/风格卡引用），语义层与模型层分离。

| 动作 | 姿势 | 挂载 | 风险 |
|---|---|---|---|
| reuse_result（R键）从回填图片升维为回填配方 | 深化 | workstation-commands | 低 |
| showcase 案例携带完整 payload＋「用此工作流打开」；历史「发布为案例」 | 吸收 | showcase-cases × workflow-recall | 低 |
| 模板 = 六槽具名 profile（风格 chips＋3x3 分镜）＋模板捕获器（任何出图一键存模板） | 深化 | prompt optimizer | 低 |
| 历史「再来 N 组／微调变体」（--r/Vary 等价） | 吸收 | server-history-store × agent-batch-anchor | 低 |
| ComfyUI PNG tEXt chunk 导入解析（互联网百万级存量资产变免费迁移钩子，对手架构无法反制） | 吸收 | workflow-png | 中 |
| 风格卡＝可分享可组合资产（反杀 sref 模型绑定） | 吸收 | character-card-store 扩展 | 中 |
| 配方跨模型自动重参数化（语义层保留、模型层按能力矩阵映射）——**全行业空白位，General 定位护城河本体** | 深化 | workflow-recall 分层 × model-status | 中 |
| workflow-png 全量默认配方（每张外流图=自证可再生的回流钩子） | 深化 | workflow-png | 低 |

**吊打位**：对手配方绑死自家模型/节点图；我们的配方模型 id 显式参数化＋跨模型可移植——「工作流不被模型锁死」是聚合架构独有命题。

## 主线二：跨模型纵深（聚合架构结构性优势）

- **参数扫描矩阵**（同 prompt 跨模型/跨参数网格对比，九宫格抽卡是退化特例）→ 深化，挂队列+历史｜低风险
- **Draft 草稿批量档**（n 张低解析度 1/5 币，选中一键高清重跑；跨模型草稿→精修：Flux 草稿 GPT Image 精修）→ 吸收，挂提交参数＋帐本档位｜低风险
- **tryouts 方案级并行候选**（diverge_by: model/style_slot/composition，确认卡并排挑）→ 深化，挂批量愿望引擎｜中风险
- **角色卡锚定图＋权重**（贯穿图像+影片的一致性资产，跨 40+ 模型＋自动路由避开弱项；MJ Omni Ref 限制清单=我们的差异化清单）→ 深化，挂 character-cards×edits｜中风险
- **同主体×风格矩阵批量**（豆包 36 张的一般化：轴可自定义、任一格可点入迭代）→ 深化，挂批量愿望六槽｜中风险
- **/compare 同 prompt 跨模型实测对比系列**（唯一有资格做全厂商横评的主体，截流已验证的选型搜索流量）→ 吸收，挂 use-cases 路由族｜低风险

## 主线三：信任中心（B 端，咬合结构一次开发多个卖点）

共用三个数据源（三阶段帐本＋金丝雀/对帐＋routing-telemetry），合成一个「信任中心」：

1. **反掺水可验证计费**：每请求附计费凭证引用（上游用量原文/倍率/coins 扣减），GET /v1/charges/{id}——对手只有承诺，我们有单据；中转市场最大信任焦虑（B站/36氪实锤）的精确解药｜低
2. **Status Page＋模型级 availability 历史**（supplier 健康快照＋24h 成功率按模型=组件渲染）｜低
3. **三联预警**（余量/限额/模型退役，走 callback outbox 同一 HMAC 通道，带 replacement_model＋价差）｜低
4. **Callback 契约文档化＋delivery 查询＋死信 replay＋JWKS 升级**（outbox 数据已在）｜低-中
5. **模型上下线公告频道**（scheduled_offline_at/replacement_model 结构化字段，调度器副产品派生，客户 SDK 可编程消费）｜低
6. **失败语义 API**（failure-classifier 四分类映射 typed error＋availability object＋retry_after）｜低
7. **urgency 计费参数**（immediate/overnight/offpeak 倍率，batch 半价=offpeak 语义糖；离峰任务导向冷却供应商容量）｜中
8. **llms.txt＋MCP**（llms.txt 带 model-status 即时可用性，静态索引对手做不到）｜极低
9. **实测 SLO 公开榜单**（SLO 查询的匿名聚合视图，多供应商交叉验证的生产数据）｜低
10. **进入社区榜单**（aiapipk/relayAPI/awesome-ai-proxy 提交收录，零开发）｜零
11. **B 端 :free 免费面**（低成本渠道每日限额，切入白嫖→付费路径；免费用户自动进 offpeak 队列消化离峰容量）｜中
12. **金钥管理 API**（/v1/keys CRUD＋per-key 限额直通帐本，零售商→带审计的批发商）｜中
13. **Playground＋跑前估价**（skus 即时算币，试跑走完整帐本含凭证）｜中高

## 主线四：模型知识面外化（一份数据多个消费端）

**模型卡**挂 generation-model-catalog：strengths/knownDefects/usageTips/releaseNotes/调用量/7天成功率/p95——同时喂三个消费端：①模型选择器即时展开（选型点）②生成路由约束（自动排除不支持功能组合的模型）③优化器模型感知（usageTips 自动注入规避词，知识在生成前自动生效）。素材来源：reddit-use-cases 语料＋内部 SLO 脱敏＋外部榜单结论。失败归因反链模型卡推荐替代模型——知识从内容变系统行为。｜低

配套：模型词典（高频高成功 token 从任务 DB 自动沉淀，内容成本趋零）、场景化选型导购视图（数据驱动、跨厂商中立——官方文档的死穴）。

## 主线五：场景引擎 profile 化（对手专属模式沦为我们的 profile）

- **运镜/景别词库**（景别×运镜×视角×光线可组合词维度，词条附真实出片缩略图=可视化选频器）→ 深化 style-library｜低
- **套图包 profile**（平台包=尺寸组+模板位+语言位声明式配置；每张共享角色卡/商品图引用，改一处全套重派；短剧海报包/小说封面包同构）→ 深化 ad-formats｜低
- **分镜表工作流**（剧本→结构化镜头表→逐镜生成自动拼接角色卡→并排连戏检查；每格可编辑+跨模型重跑单镜；镜头表沉淀为可分享资产）→ 吸收 scenario-templates×character-cards｜中（需求侧 B站已自燃）
- **角色卡触发注入**（trigger keywords+变体描述，Lorebook 机制跨媒体生效）→ 深化 character-cards｜中
- **多选区独立指令**（选区=画布指令区非编辑模式；MJ Editor 卡 V6.1=专属模式枷锁实锤；选区进配方快照+失败分类器单选区重跑）→ 深化 canvas×edits｜中
- **指令卡**（换光/机位/色板=选区×结构化词库组合，跨模型组合）→ 深化 A1×六槽｜中
- **白底→场景/平铺→模特上身向导**（用户自有模特照/角色卡驱动，人设资产归用户；结果直挂套图包）→ 吸收 commerce 卷×edits｜中
- **multi-shot 参数透传**（镜头表跨 Veo/Kling/Seedance 对比出片；供应商验证先行）→ 吸收 B 端视频端点｜中高
- **配额回退而非硬断**（coins 尽自动降级免费池，跨供应商真降级——Gemini 只能回退自家；降级×转化数据回流帐本）→ 吸收 quota×失败分类器｜低-中

## 主线六：商业化与成长（挂 tier-pricing/帐本/aff/CheckinCalendar 既有 owner）

**第一梯队（并列）**：首充折扣系数＋退款/保价公示——即梦三连涨＋Freepik 回收「不限量」两案例实锤：tier-pricing 动态定价必然遇到改价场景，保价规则（N 日内降价补差 coins）是动态定价的安全带，与首充同期上线。

其余：定价页每币单价矩阵+张数换算（活数据非静态表）｜年付 SKU｜功能门槛（排程优先级+去水印，能力差异化>币量差异化）｜任务链签到＋**签到里程碑**（7/30/100 天大额爆发奖，对标 PixAI DAU 机器，挂 CheckinCalendar+文案系统）｜邀请双向得币＋**受邀者首月充值 +30% coins 返还**（设上限，挂 tier-pricing 折扣系数，对标可灵）｜学生价（GitHub Student Pack）｜滚存规则透明+加购币包。｜全低-中风险

**防刷铁律（2026-08-25 社区证据升级）**：B站「即梦无限白嫖积分/注册机」已是内容品类——所有赠币类功能（签到/任务/邀请/免费池）以「设备+支付指纹去重＋每日上限」为前置验收条件，不另立条目。

战略位（单独排期）：创作者分成+UGC 市场（吊打度最高、风险最高，等配方总线数据闭环+DAU 起来后以 showcase 排序/专题形态出现，零新系统）。

## 全局排期（吊打彻底度 × 风险倒数）

**第一波（并行一个 sprint，全是低风险）**：配方总线核心（R键回填配方+案例双向化+模板捕获器+再来N组）｜模型卡三字段｜运镜词库｜信任中心 v1（可验证计费凭证+status page+不掺水验证包）｜llms.txt｜定价张数换算｜社区榜单提交（运营）。

**第三波（中风险主菜）**：配方跨模型重参数化（护城河本体）｜分镜表工作流｜多选区指令｜tryouts｜角色卡锚定+触发注入｜风格卡｜urgency 计费参数｜JWKS+delivery 查询。

**验证队列（依赖上游，不阻塞主线）**：multi-shot 透传｜模特上身保真度｜LoRA 线上训练（第三方 API）｜:free 免费面成本核算。

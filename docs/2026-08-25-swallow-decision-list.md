# 吞併決策總清單（2026-08-25，11 卷競品偵察 × PM 對稱差框架）

> 框架：吞什麼／什麼姿勢吞（【深化】=對手淺層特化→我們的一般化機制；【吸收】=獨立能力→工作台一等公民、入口統一；【不吞】=與 General 定位衝突）。鐵律：全部掛現有 owner，零新系統零新入口；特化一律以參數化/profile 進入。證據見各卷偵察報告（會話存檔）。

## 主線一：配方資產總線（7 卷獨立匯合，第一排期）

**吞併對象**：即夢/Liblib 做同款、Civitai 工作流下載、MJ --r/Vary、MJ --sref、workflow-png 導入、Krea 會話→pipeline、Lovart 模板櫥窗。

**統一機制**：規範化「配方」對象 = workflow-recall payload（六槽 prompt＋模型 id＋尺寸＋參考圖角色＋區域 prompt＋角色卡/風格卡引用），語義層與模型層分離。

| 動作 | 姿勢 | 掛載 | 風險 |
|---|---|---|---|
| reuse_result（R鍵）從回填圖片升維為回填配方 | 深化 | workstation-commands | 低 |
| showcase 案例攜帶完整 payload＋「用此工作流打開」；歷史「發佈為案例」 | 吸收 | showcase-cases × workflow-recall | 低 |
| 模板 = 六槽具名 profile（風格 chips＋3x3 分鏡）＋模板捕獲器（任何出圖一鍵存模板） | 深化 | prompt optimizer | 低 |
| 歷史「再來 N 組／微調變體」（--r/Vary 等價） | 吸收 | server-history-store × agent-batch-anchor | 低 |
| ComfyUI PNG tEXt chunk 導入解析（互聯網百萬級存量資產變免費遷移鉤子，對手架構無法反制） | 吸收 | workflow-png | 中 |
| 風格卡＝可分享可組合資產（反殺 sref 模型綁定） | 吸收 | character-card-store 擴展 | 中 |

## 主線二：跨模型縱深（聚合架構結構性優勢）

- **參數掃描矩陣**（同 prompt 跨模型/跨參數網格對比，九宮格抽卡是退化特例）→ 深化，掛隊列+歷史｜低風險
- **Draft 草稿批量檔**（n 張低解析度 1/5 幣，選中一鍵高清重跑；跨模型草稿→精修：Flux 草稿 GPT Image 精修）→ 吸收，掛提交參數＋帳本檔位｜低風險
- **tryouts 方案級並行候選**（diverge_by: model/style_slot/composition，確認卡並排挑）→ 深化，掛批量願望引擎｜中風險
- **角色卡錨定圖＋權重**（貫穿圖像+影片的一致性資產，跨 40+ 模型＋自動路由避開弱項；MJ Omni Ref 限制清單=我們的差異化清單）→ 深化，掛 character-cards×edits｜中風險
- **同主體×風格矩陣批量**（豆包 36 張的一般化：軸可自定義、任一格可點入迭代）→ 深化，掛批量願望六槽｜中風險
- **/compare 同 prompt 跨模型實測對比系列**（唯一有資格做全廠商橫評的主體，截流已驗證的選型搜索流量）→ 吸收，掛 use-cases 路由族｜低風險

## 主線三：信任中心（B 端，咬合結構一次開發多個賣點）

共用三個數據源（三階段帳本＋金絲雀/對帳＋routing-telemetry），合成一個「信任中心」：

1. **反摻水可驗證計費**：每請求附計費憑證引用（上游用量原文/倍率/coins 扣減），GET /v1/charges/{id}——對手只有承諾，我們有單據；中轉市場最大信任焦慮（B站/36氪實錘）的精確解藥｜低
2. **Status Page＋模型級 availability 歷史**（supplier 健康快照＋24h 成功率按模型=組件渲染）｜低
3. **三聯預警**（餘量/限額/模型退役，走 callback outbox 同一 HMAC 通道，帶 replacement_model＋價差）｜低
4. **Callback 契約文檔化＋delivery 查詢＋死信 replay＋JWKS 升級**（outbox 數據已在）｜低-中
5. **模型上下線公告頻道**（scheduled_offline_at/replacement_model 結構化字段，調度器副產品派生，客戶 SDK 可編程消費）｜低
6. **失敗語義 API**（failure-classifier 四分類映射 typed error＋availability object＋retry_after）｜低
7. **urgency 計費參數**（immediate/overnight/offpeak 倍率，batch 半價=offpeak 語義糖；離峰任務導向冷卻供應商容量）｜中
8. **llms.txt＋MCP**（llms.txt 帶 model-status 即時可用性，靜態索引對手做不到）｜極低
9. **實測 SLO 公開榜單**（SLO 查詢的匿名聚合視圖，多供應商交叉驗證的生產數據）｜低
10. **進入社區榜單**（aiapipk/relayAPI/awesome-ai-proxy 提交收錄，零開發）｜零
11. **B 端 :free 免費面**（低成本渠道每日限額，切入白嫖→付費路徑；免費用戶自動進 offpeak 隊列消化離峰容量）｜中
12. **金鑰管理 API**（/v1/keys CRUD＋per-key 限額直通帳本，零售商→帶審計的批發商）｜中
13. **Playground＋跑前估價**（skus 即時算幣，試跑走完整帳本含憑證）｜中高

## 主線四：模型知識面外化（一份数據多個消費端）

**模型卡**掛 generation-model-catalog：strengths/knownDefects/usageTips/releaseNotes/調用量/7天成功率/p95——同時餵三個消費端：①模型選擇器即時展開（選型點）②生成路由約束（自動排除不支持功能組合的模型）③優化器模型感知（usageTips 自動注入規避詞，知識在生成前自動生效）。素材來源：reddit-use-cases 語料＋內部 SLO 脫敏＋外部榜單結論。失敗歸因反鏈模型卡推薦替代模型——知識從內容變系統行為。｜低

配套：模型詞典（高頻高成功 token 從任務 DB 自動沉澱，內容成本趨零）、場景化選型導購視圖（數據驅動、跨廠商中立——官方文檔的死穴）。

## 主線五：場景引擎 profile 化（對手專屬模式淪為我們的 profile）

- **運鏡/景別詞庫**（景別×運鏡×視角×光線可組合詞維度，詞條附真實出片縮略圖=可視化選頻器）→ 深化 style-library｜低
- **套圖包 profile**（平台包=尺寸組+模板位+語言位聲明式配置；每張共享角色卡/商品圖引用，改一處全套重派；短劇海報包/小說封面包同構）→ 深化 ad-formats｜低
- **分鏡表工作流**（劇本→結構化鏡頭表→逐鏡生成自動拼接角色卡→並排連戲檢查；每格可編輯+跨模型重跑單鏡；鏡頭表沉澱為可分享資產）→ 吸收 scenario-templates×character-cards｜中（需求側 B站已自燃）
- **角色卡觸發注入**（trigger keywords+變體描述，Lorebook 機制跨媒體生效）→ 深化 character-cards｜中
- **多選區獨立指令**（選區=畫布指令區非編輯模式；MJ Editor 卡 V6.1=專屬模式枷鎖實錘；選區進配方快照+失敗分類器單選區重跑）→ 深化 canvas×edits｜中
- **指令卡**（換光/機位/色板=選區×結構化詞庫組合，跨模型組合）→ 深化 A1×六槽｜中
- **白底→場景/平鋪→模特上身嚮導**（用戶自有模特照/角色卡驅動，人設資產歸用戶；結果直掛套圖包）→ 吸收 commerce 卷×edits｜中
- **multi-shot 參數透傳**（鏡頭表跨 Veo/Kling/Seedance 對比出片；供應商驗證先行）→ 吸收 B 端視頻端點｜中高
- **配額回退而非硬斷**（coins 盡自動降級免費池，跨供應商真降級——Gemini 只能回退自家；降級×轉化數據回流帳本）→ 吸收 quota×失敗分類器｜低-中

## 主線六：商業化與成長（掛 tier-pricing/帳本/aff/CheckinCalendar 既有 owner）

**第一梯隊（並列）**：首充折扣係數＋退款/保價公示——即夢三連漲＋Freepik 回收「不限量」兩案例實錘：tier-pricing 動態定價必然遇到改價場景，保價規則（N 日內降價補差 coins）是動態定價的安全帶，與首充同期上線。

其餘：定價頁每幣單價矩陣+張數換算（活數據非靜態表）｜年付 SKU｜功能門檻（排程優先級+去水印，能力差異化>幣量差異化）｜任務鏈簽到＋**簽到里程碑**（7/30/100 天大額爆發獎，對標 PixAI DAU 機器，掛 CheckinCalendar+文案系統）｜邀請雙向得幣＋**受邀者首月充值 +30% coins 返還**（設上限，掛 tier-pricing 折扣係數，對標可靈）｜學生價（GitHub Student Pack）｜滾存規則透明+加購幣包。｜全低-中風險

**防刷鐵律（2026-08-25 社區證據升級）**：B站「即夢無限白嫖積分/註冊機」已是內容品類——所有贈幣類功能（簽到/任務/邀請/免費池）以「設備+支付指紋去重＋每日上限」為前置驗收條件，不另立條目。

戰略位（單獨排期）：創作者分成+UGC 市場（吊打度最高、風險最高，等配方總線數據閉環+DAU 起來後以 showcase 排序/專題形態出現，零新系統）。

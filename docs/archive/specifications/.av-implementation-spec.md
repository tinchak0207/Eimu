工作区：/home/lenovo/Desktop/image-app（Next.js 15 + TS）。目标：为 B 端成片链路补上配音 TTS / 数字人口播 / 唇形能力节点，全部接上游 API，不自研模型。

## 环境注意
- node 不在 PATH：所有 node/npm/npx 命令前缀 `source ~/.nvm/nvm.sh && `。
- 本 harness 的工具输出层会搅乱含 CJK（中文）的输出：读含中文注释的档案时用 base64 传输（bash 执行 `sed -n 'X,Yp' <file> | base64 -w0 && echo`，把输出 base64 decode 后再看）；或 grep ASCII 模式。被搅乱的输出症状是 "clean — nothing to commit" 或行序错乱，不要相信。
- 禁止碰 src/components/canvas/ 与 src/lib/canvas/types.ts（另一 subagent 在改）。
- 禁止修改任何既有 .test.ts 档案的断言（可以新增测试档案）。
- 不要部署（vercel / VPS 由上层处理）。

## 架构背景（已侦察证实）
- 生成核心 src/lib/generation-core/：command-service 的 submitGenerationCommand（建 generation_job 行 → hasGenerationCapability 检查 → reserveGenerationBilling）→ worker-service runGenerationWorkerOnce（claimNextGenerationJob → acquireSupplierLease（按 supplier_capability.kind 匹配）→ generateWithSupplier → persistOutputArtifact → completeGenerationJob / 计费 commit）。
- DB 表：generation_job.kind 与 supplier_capability.kind 是 text + CHECK（现值 image_generate/image_edit/video_generate）；supplier.adapter_type CHECK（adobe2api/openai_images）。supplier 供应商记录存在 VPS DB（id 如 env:minimax-tts），credential_ref 指向 env 变数名。
- 既有路由模式（动手前先读这三个档案照抄形状）：POST src/app/api/v1/videos/generations/route.ts（authenticateBizApiKey(readBearerToken(req.headers.get("authorization"))) → body 校验 → syncModelPricing() → generationControlPlaneEnabled() 检查 → submitGenerationCommand → 202 + Location + generationTaskResponse）；GET src/app/api/v1/videos/[id]/route.ts（鉴权 { consumeRateLimit: false } → getGenerationJobForTenant(id, `biz:${auth.key.id}`) → generationTaskResponse）；GET src/app/api/v1/videos/[id]/result/route.ts（同上 + taskStatus(job)==="succeeded" 检查 → artifacts[0]?.url）。错误回应形状 {error:{message,type,code,param:null,trace_id}} + withTraceId。
- trace：getOrCreateTraceId/withTraceId（src/lib/request-trace）；幂等：Idempotency-Key header（submitGenerationCommand 已处理，IdempotencyConflictError → 409 idempotency_key_reused）。

## 设计决策（已定，不要改）
- 新 GenerationKind："tts" | "avatar" | "lipsync"。
- 上游适配器两个具名但全配置驱动：adapter_type "minimax"（TTS，POST {base}/v1/t2a_v2，同步回 hex 音频）与 "did"（avatar+lipsync，POST {base}/talks 提交 → 轮询 GET {base}/talks/{id} → result_url mp4）。base_url、credential_ref（env 变数名）、supplier_model_id 全由 DB supplier 行驱动；真实 key 由主人后填（文档写清步骤）。

## 12. src/lib/biz-av-pipeline.ts（新）+ biz-av-pipeline.test.ts
```ts
export type AvSubmissionKind = "tts" | "avatar" | "lipsync";
export interface TtsSubmission { modelId: string; text: string; voice: string | null; speed: number | null; format: string | null; callbackUrl: string | null; }
export interface AvatarSubmission { modelId: string; presenterId: string | null; imageUrl: string | null; audioUrl: string | null; text: string | null; voice: string | null; resolution: string | null; callbackUrl: string | null; }
export interface LipsyncSubmission { modelId: string; imageUrl: string; audioUrl: string; resolution: string | null; callbackUrl: string | null; }
export type AvParseResult<T> = { ok: true; value: T } | { ok: false; message: string; code: string };
export function parseTtsBody(body: unknown): AvParseResult<TtsSubmission>
export function parseAvatarBody(body: unknown): AvParseResult<AvatarSubmission>
export function parseLipsyncBody(body: unknown): AvParseResult<LipsyncSubmission>
export function avPromptFor(kind: AvSubmissionKind, submission: TtsSubmission | AvatarSubmission | LipsyncSubmission): string
export function avWorkflowFor(kind: AvSubmissionKind, submission: TtsSubmission | AvatarSubmission | LipsyncSubmission): Record<string, unknown>
export const AV_DEADLINE_MS: { tts: number; avatar: number; lipsync: number } // 300_000 / 720_000 / 720_000
```
校验规则：
- 共通：model 必须非空 string；callback_url 可选 http(s) ≤2048；voice/presenter_id 模式 /^[A-Za-z0-9_.\-]{1,128}$/（非法 400 invalid_voice/invalid_presenter_id）；url 栏位必须 http(s) 且 ≤2048（invalid_url）。
- tts：input 或 text 择一（优先 input）非空 ≤10_000 字元（missing_input/prompt_too_long）；speed 数字 0.5–2（越界 clamp 到区间，非有限数字 400 invalid_speed）；response_format 或 audio_format ∈ mp3|wav|flac|pcm（其他 400 invalid_format）。
- avatar：presenter_id 与 image_url 至少一个（missing_source）；input/text 与 audio_url 至少一个（missing_script）。
- lipsync：image_url 与 audio_url 都必填（missing_image_url / missing_audio_url）。
- n 栏位若存在且 Number(n) !== 1 → 400 invalid_n（"n must be 1 for AV pipelines."）。
avPromptFor：tts→text；avatar→text ?? `[audio] ${audioUrl}`；lipsync→`[lipsync] ${imageUrl} ${audioUrl}`。
avWorkflowFor：tts → {voice, speed, format}（null 略）；avatar → {presenterId, imageUrl, audioUrl, voice, resolution}（null 略）；lipsync → {imageUrl, audioUrl, resolution}。
测试（纯函数）：缺栏位各 400、speed clamp、url 校验、lipsync 双必填、n≠1 拒绝、prompt/workflow 生成断言。
